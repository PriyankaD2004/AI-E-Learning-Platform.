# AI E-Learning Platform

## Overview

The AI E-Learning Platform is an intelligent web-based learning system that leverages Generative AI to automate educational content creation and provide personalized learning assistance. Traditional e-learning platforms often depend on manually created course materials, which limits scalability and flexibility. This platform addresses these challenges by automatically generating course content, lessons, study notes, quizzes, and real-time academic support through an AI Tutor.

## Features

### Course Enrollment

* Browse and enroll in available courses.
* Access personalized learning content based on selected subjects.

### AI Course Generation

* Automatically generates complete course outlines.
* Creates structured learning paths for selected topics.

### AI Lesson Generation

* Generates detailed lessons with comprehensive explanations.
* Organizes content into logical modules and topics.

### AI Study Notes

* Produces downloadable and offline-accessible study notes.
* Helps learners revise and retain knowledge effectively.

### Quiz Generation and Evaluation

* Generates quizzes based on completed lessons.
* Provides instant scoring and performance evaluation.
* Displays correct answers and explanations for incorrect responses.

### AI Tutor

* Real-time chat-based academic assistance.
* Answers learner questions and clarifies doubts.
* Provides personalized learning support and guidance.

### Admin Dashboard

* Manage users, courses, lessons, quizzes, and notes.
* Monitor platform activities and learning progress.
* Maintain and control platform operations efficiently.

## Installation

### Clone the Repository

```bash
git clone https://github.com/PriyankaD2004/AI-E-Learning-Platform..git
cd AI-E-Learning-Platform
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / macOS

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

The application will run locally and can be accessed through your browser.
