## Python: Core Concepts & Notes

### 1. Introduction to Python

*   **What is Python?**
    *   High-level, interpreted, general-purpose programming language.
    *   Created by Guido van Rossum and first released in 1991.
    *   Known for its readability and simplicity.
*   **Key Features:**
    *   **Simple & Readable:** Emphasizes code readability with clear syntax.
    *   **Interpreted:** Code is executed line by line, no compilation step (like C++).
    *   **Dynamically Typed:** Variable types are determined at runtime. You don't declare `int x = 5;`.
    *   **Cross-platform:** Runs on Windows, macOS, Linux, etc., often with minimal changes.
    *   **Object-Oriented:** Supports OOP principles (classes, objects, inheritance).
    *   **Extensible:** Can be extended with modules written in C/C++.
    *   **Large Standard Library:** Rich set of modules and packages for various tasks.
    *   **Extensive Community & Ecosystem:** Vast libraries (NumPy, Pandas, Django, Flask, TensorFlow).
*   **Common Use Cases:**
    *   Web Development (Django, Flask, FastAPI)
    *   Data Science & Machine Learning (Pandas, NumPy, Scikit-learn, TensorFlow, PyTorch)
    *   Automation & Scripting
    *   GUI Development (Tkinter, PyQt)
    *   Networking & System Administration
    *   Game Development (Pygame)

### 2. Getting Started & Setup

*   **Installation:**
    *   Download from `python.org` (recommended).
    *   Use package managers (e.g., `apt` on Linux, `brew` on macOS).
*   **Verify Installation:**
    ```bash
    python --version # or python3 --version
    ```
*   **Package Installer (`pip`):**
    *   Used to install third-party Python packages.
    *   `pip install <package_name>`
    *   `pip install -r requirements.txt` (install from a list)
    *   `pip freeze > requirements.txt` (generate a list of installed packages)
*   **Virtual Environments (Crucial!):**
    *   Isolate project dependencies from each other and the global Python installation.
    *   **Creation:**
        ```bash
        python -m venv my_project_env
        ```
    *   **Activation:**
        *   **Windows:** `my_project_env\Scripts\activate`
        *   **macOS/Linux:** `source my_project_env/bin/activate`
    *   **Deactivation:** `deactivate`

### 3. Basic Syntax & Fundamentals

*   **Comments:**
    ```python
    # This is a single-line comment

    """
    This is a
    multi-line string,
    often used as a docstring or
    a multi-line comment.
    """
    ```
*   **Indentation:**
    *   **Mandatory:** Defines code blocks (e.g., inside `if` statements, loops, functions).
    *   **Standard:** 4 spaces per indentation level (never tabs).
*   **Variables:**
    *   No explicit declaration; type is inferred.
    *   Case-sensitive (`myVar` is different from `myvar`).
    *   **Naming Conventions (PEP 8):**
        *   `snake_case` for variables, functions, modules.
        *   `PascalCase` for classes.
        *   `ALL_CAPS` for constants.
    ```python
    name = "Alice"
    age = 30
    is_student = True
    ```
*   **Output:**
    ```python
    print("Hello, Python!")
    print("Name:", name, "Age:", age)
    print(f"Name: {name}, Age: {age}") # f-string (formatted string literal)
    ```
*   **Input:**
    ```python
    user_input = input("Enter your name: ")
    print(f"Hello, {user_input}")
    ```

### 4. Data Types

*   **Numbers:**
    *   `int`: Integers (e.g., `5`, `-100`)
    *   `float`: Floating-point numbers (e.g., `3.14`, `-0.5`)
    *   `complex`: Complex numbers (e.g., `1 + 2j`)
*   **Strings (`str`):**
    *   Sequence of characters. Immutable.
    *   Defined with single (`'...'`), double (`"..."`), or triple quotes (`"""..."""` for multi-line).
    *   **Concatenation:** `str1 + str2`
    *   **Indexing & Slicing:**
        ```python
        my_string = "Python"
        print(my_string[0])   # P
        print(my_string[1:4]) # yth
        print(my_string[-1])  # n
        ```
    *   **Methods:** `.upper()`, `.lower()`, `.strip()`, `.split()`, `.replace()`, `.find()`, `.count()`
*   **Booleans (`bool`):**
    *   `True` or `False` (case-sensitive).
*   **`None` Type:**
    *   Represents the absence of a value or a null value.

### 5. Operators

*   **Arithmetic:** `+`, `-`, `*`, `/` (float division), `//` (integer division), `%` (modulo), `**` (exponentiation)
*   **Comparison:** `==` (equal to), `!=` (not equal to), `<`, `>`, `<=`, `>=`
*   **Logical:** `and`, `or`, `not`
*   **Assignment:** `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`, `//=`
*   **Identity:** `is`, `is not` (checks if two variables refer to the *same object* in memory)
*   **Membership:** `in`, `not in` (checks if a value exists within a sequence)

### 6. Control Flow

*   **Conditional Statements (`if`, `elif`, `else`):**
    ```python
    age = 18
    if age < 13:
        print("Child")
    elif age < 18:
        print("Teenager")
    else:
        print("Adult")
    ```
*   **`for` Loops:**
    *   Iterate over sequences (lists, tuples, strings, dictionaries, range).
    ```python
    for char in "Python":
        print(char)

    for i in range(5): # 0, 1, 2, 3, 4
        print(i)

    # Iterating with index
    my_list = ['a', 'b', 'c']
    for index, value in enumerate(my_list):
        print(f"{index}: {value}")
    ```
*   **`while` Loops:**
    *   Execute a block of code repeatedly as long as a condition is true.
    ```python
    count = 0
    while count < 3:
        print(count)
        count += 1
    ```
*   **`break` & `continue`:**
    *   `break`: Exits the loop entirely.
    *   `continue`: Skips the rest of the current iteration and moves to the next.

### 7. Functions

*   **Definition:** Defined using the `def` keyword.
    ```python
    def greet(name):
        """This function greets the person passed in as a parameter."""
        return f"Hello, {name}!"

    message = greet("Bob")
    print(message)
    ```
*   **Parameters & Arguments:**
    *   **Positional Arguments:** Passed in order.
    *   **Keyword Arguments:** Passed by name (e.g., `greet(name="Charlie")`).
    *   **Default Arguments:**
        ```python
        def power(base, exp=2):
            return base ** exp
        print(power(3))    # 9 (3**2)
        print(power(3, 3)) # 27 (3**3)
        ```
    *   **Arbitrary Arguments (`*args`, `**kwargs`):**
        *   `*args`: Collects positional arguments into a tuple.
        *   `**kwargs`: Collects keyword arguments into a dictionary.
        ```python
        def func(*args, **kwargs):
            print("Positional:", args)
            print("Keywords:", kwargs)
        func(1, 2, a=3, b=4)
        ```
*   **Return Values:** `return` statement sends a value back from the function. If omitted, `None` is returned implicitly.
*   **Lambda Functions (Anonymous Functions):**
    *   Small, single-expression functions.
    *   Syntax: `lambda arguments: expression`
    ```python
    add_one = lambda x: x + 1
    print(add_one(5)) # 6
    ```

### 8. Data Structures

*   **Lists (`list`):**
    *   Ordered, mutable (changeable) sequence of elements.
    *   Defined by square brackets `[]`.
    *   Can contain elements of different types.
    *   **Methods:** `append()`, `insert()`, `remove()`, `pop()`, `sort()`, `reverse()`, `index()`, `count()`
    ```python
    my_list = [1, "hello", 3.14, True]
    my_list.append(4) # [1, "hello", 3.14, True, 4]
    my_list[0] = 0    # [0, "hello", 3.14, True, 4]
    ```
*   **Tuples (`tuple`):**
    *   Ordered, **immutable** (unchangeable) sequence of elements.
    *   Defined by parentheses `()`.
    *   Faster for fixed collections of items.
    *   **Methods:** `count()`, `index()` (fewer methods than lists due to immutability).
    ```python
    my_tuple = (1, "hello", 3.14)
    # my_tuple[0] = 0 # Error: Tuples are immutable
    ```
*   **Dictionaries (`dict`):**
    *   Unordered, mutable collection of **key-value pairs**.
    *   Keys must be unique and immutable (strings, numbers, tuples). Values can be any type.
    *   Defined by curly braces `{}`.
    *   **Methods:** `get()`, `keys()`, `values()`, `items()`, `update()`, `pop()`, `clear()`
    ```python
    my_dict = {"name": "Alice", "age": 30}
    print(my_dict["name"]) # Alice
    my_dict["age"] = 31
    my_dict["city"] = "NY"
    print(my_dict.get("country", "USA")) # Returns 'USA' if 'country' not found
    ```
*   **Sets (`set`):**
    *   Unordered, mutable collection of **unique** elements.
    *   Defined by curly braces `{}` or `set()`.
    *   Useful for membership testing and eliminating duplicate entries.
    *   **Set Operations:** Union (`|`), Intersection (`&`), Difference (`-`), Symmetric Difference (`^`)
    ```python
    my_set = {1, 2, 3, 2} # {1, 2, 3} (duplicates removed)
    my_set.add(4)        # {1, 2, 3, 4}
    ```

### 9. Modules and Packages

*   **Modules:**
    *   A `.py` file containing Python definitions and statements.
    *   Organizes code into logical units.
    *   **Importing:**
        ```python
        import math
        print(math.pi)

        from datetime import date
        print(date.today())

        import random as rnd
        print(rnd.randint(1, 10))
        ```
*   **Packages:**
    *   A directory containing modules and a special `__init__.py` file (though less critical in modern Python for simple packages).
    *   Provides a way to organize related modules into a directory hierarchy.
    *   `from package_name import module_name`

### 10. Object-Oriented Programming (OOP)

*   **Classes:** Blueprint for creating objects.
    *   Defined using the `class` keyword.
    *   Contain attributes (data) and methods (functions).
*   **Objects (Instances):** Real-world entities created from a class.
*   **`self`:**
    *   Refers to the instance of the class. Must be the first parameter of any instance method.
*   **`__init__` (Constructor):**
    *   A special method called when an object is created.
    *   Used to initialize object attributes.
    ```python
    class Dog:
        def __init__(self, name, breed):
            self.name = name
            self.breed = breed

        def bark(self):
            return f"{self.name} says Woof!"

    my_dog = Dog("Buddy", "Golden Retriever")
    print(my_dog.bark())
    ```
*   **Inheritance:**
    *   Allows a class (child/derived) to inherit attributes and methods from another class (parent/base).
    ```python
    class Labrador(Dog): # Labrador inherits from Dog
        def __init__(self, name, color):
            super().__init__(name, "Labrador") # Call parent constructor
            self.color = color

        def retrieve(self):
            return f"{self.name} retrieves the ball."
    ```

### 11. File I/O (Input/Output)

*   **Opening Files:** `open(filename, mode)`
    *   `mode`: `'r'` (read, default), `'w'` (write, truncates existing), `'a'` (append), `'x'` (create new file, error if exists), `'b'` (binary), `'t'` (text, default)
*   **Reading:**
    *   `f.read()`: Reads entire file content.
    *   `f.readline()`: Reads one line at a time.
    *   `f.readlines()`: Reads all lines into a list.
*   **Writing:**
    *   `f.write(string)`: Writes a string.
    *   `f.writelines(list_of_strings)`: Writes a list of strings.
*   **Closing Files:** `f.close()` (important to free up resources).
*   **Context Manager (`with` statement - Best Practice):**
    *   Ensures files are automatically closed, even if errors occur.
    ```python
    # Writing to a file
    with open("my_file.txt", "w") as f:
        f.write("Hello from Python!\n")
        f.write("This is a second line.")

    # Reading from a file
    with open("my_file.txt", "r") as f:
        content = f.read()
        print(content)
    ```

### 12. Error Handling

*   **`try`, `except`, `else`, `finally`:**
    *   `try`: Code that might raise an exception.
    *   `except`: Catches and handles specific exceptions.
    *   `else`: Executed if no exception occurs in `try`.
    *   `finally`: Always executed, regardless of whether an exception occurred.
    ```python
    try:
        result = 10 / 0
    except ZeroDivisionError:
        print("Cannot divide by zero!")
    except TypeError as e: # Catch a specific error and its message
        print(f"Type error: {e}")
    except Exception as e: # Catch any other error
        print(f"An unexpected error occurred: {e}")
    else:
        print("Division successful, result:", result)
    finally:
        print("Execution finished.")
    ```

### 13. Advanced/Useful Concepts (Briefly)

*   **List Comprehensions:**
    *   Concise way to create lists.
    *   `[expression for item in iterable if condition]`
    ```python
    squares = [x**2 for x in range(10) if x % 2 == 0] # [0, 4, 16, 36, 64]
    ```
*   **Generators:**
    *   Functions that `yield` a sequence of values instead of returning a single value.
    *   Memory efficient for large sequences as they generate values on the fly.
    ```python
    def count_up_to(n):
        i = 0
        while i < n:
            yield i
            i += 1
    for num in count_up_to(5):
        print(num)
    ```
*   **Decorators:**
    *   Functions that modify or enhance other functions.
    *   Uses the `@` syntax.
    ```python
    def timer(func):
        import time
        def wrapper(*args, **kwargs):
            start = time.time()
            result = func(*args, **kwargs)
            end = time.time()
            print(f"{func.__name__} took {end - start:.4f} seconds")
            return result
        return wrapper

    @timer
    def long_running_function():
        sum(range(1000000))

    long_running_function()
    ```

### 14. Python Best Practices (PEP 8)

*   **Code Style Guide:** Follow PEP 8 for consistent, readable code.
*   **Indentation:** 4 spaces for each level.
*   **Line Length:** Max 79 characters.
*   **Naming Conventions:**
    *   `snake_case` for functions, variables, modules.
    *   `PascalCase` for classes.
    *   `ALL_CAPS` for constants.
*   **Docstrings:** Use triple quotes (`"""Docstring"""`) for modules, classes, and functions to explain their purpose.
*   **Comments:** Explain "why" not "what."
*   **Blank Lines:** Use to separate logical blocks of code.
*   **Imports:** Group standard library, third-party, and local imports, separated by blank lines.
