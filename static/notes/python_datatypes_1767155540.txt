Here are detailed notes on Python datatypes, covering their characteristics, syntax, common operations, and use cases.

## Python Datatypes: Detailed Notes

### Introduction to Python Datatypes

In Python, every value has a datatype. Datatypes classify data, telling us what kind of value it is and what operations can be performed on it. Python is a **dynamically typed** language, meaning you don't explicitly declare the type of a variable; Python infers it at runtime.

*   **Dynamic Typing:** Variables themselves don't have types, the *values* they hold do. A variable can point to an integer at one moment and a string the next.
    ```python
    x = 10         # x holds an integer
    x = "hello"    # Now x holds a string
    ```
*   **`type()` function:** You can check the type of any object using the built-in `type()` function.
    ```python
    print(type(10))        # <class 'int'>
    print(type("Python"))  # <class 'str'>
    ```
*   **Mutability vs. Immutability:** This is a fundamental concept in Python.
    *   **Immutable:** An object whose value cannot be changed after it is created. If you "modify" an immutable object, you are actually creating a new object. Examples: `int`, `float`, `str`, `tuple`, `frozenset`, `bytes`.
    *   **Mutable:** An object whose value *can* be changed after it is created. Modifications are done in-place, affecting the original object. Examples: `list`, `dict`, `set`, `bytearray`.

### 1. Numeric Types

Represent numbers. Python handles various types of numbers.

#### a) Integers (`int`)
*   **Definition:** Whole numbers (positive, negative, or zero) without a decimal point.
*   **Characteristics:**
    *   **Immutable:** The value of an integer cannot be changed.
    *   **Arbitrary Precision:** Integers in Python 3 have no fixed limit in size; they can be as large as your system's memory allows.
*   **Creation:** Directly by writing the number.
    ```python
    age = 30
    negative_num = -100
    big_num = 12345678901234567890
    ```
*   **Common Operations:** Arithmetic operations (`+`, `-`, `*`, `/`), floor division (`//`), modulo (`%`), exponentiation (`**`).
    ```python
    print(10 + 5)    # 15
    print(10 // 3)   # 3 (integer division)
    print(10 % 3)    # 1 (remainder)
    print(2 ** 3)    # 8 (2 to the power of 3)
    ```

#### b) Floating-Point Numbers (`float`)
*   **Definition:** Real numbers with a decimal point.
*   **Characteristics:**
    *   **Immutable:** The value of a float cannot be changed.
    *   **Precision:** Typically implemented using double-precision (64-bit) floating-point numbers, according to the IEEE 754 standard. This means they have limited precision, and some decimal numbers cannot be represented exactly (e.g., `0.1 + 0.2` is not exactly `0.3`).
*   **Creation:** Directly by writing the number with a decimal point.
    ```python
    pi = 3.14159
    temperature = -10.5
    scientific_notation = 6.022e23 # 6.022 * 10^23
    ```
*   **Common Operations:** Similar to integers, but results are floats.
    ```python
    print(7.0 / 2.0)  # 3.5
    print(0.1 + 0.2)  # 0.30000000000000004 (precision issue)
    ```

#### c) Complex Numbers (`complex`)
*   **Definition:** Numbers with a real and an imaginary part, written as `a + bj`, where `a` is the real part, `b` is the imaginary part, and `j` (or `J`) represents the imaginary unit (sqrt(-1)).
*   **Characteristics:**
    *   **Immutable:** The value cannot be changed.
    *   **Use Case:** Primarily used in scientific and engineering applications.
*   **Creation:** Using the `j` suffix for the imaginary part.
    ```python
    c1 = 2 + 3j
    c2 = -1.5 - 0.5j
    print(c1.real)      # 2.0
    print(c1.imag)      # 3.0
    ```
*   **Common Operations:** Addition, subtraction, multiplication, division.
    ```python
    print(c1 + c2)      # (0.5+2.5j)
    ```

### 2. Boolean Type (`bool`)

*   **Definition:** Represents truth values. There are only two possible values: `True` and `False`.
*   **Characteristics:**
    *   **Immutable:** `True` is always `True`, `False` is always `False`.
    *   **Subtype of `int`:** `True` behaves like `1`, and `False` behaves like `0` in numeric contexts, though it's generally not good practice to rely on this for arithmetic.
*   **Creation:** Directly using `True` or `False`.
    ```python
    is_active = True
    has_permission = False
    ```
*   **Use Cases:** Conditional statements (`if`, `elif`, `else`), loops (`while`), logical operations (`and`, `or`, `not`).
    ```python
    print(True and False)  # False
    print(True or False)   # True
    print(not True)        # False
    ```
*   **Truthiness/Falsiness:** Many non-boolean values are considered "truthy" or "falsy" in a boolean context:
    *   **Falsy:** `0`, `0.0`, `""` (empty string), `[]` (empty list), `()` (empty tuple), `{}` (empty dict), `set()` (empty set), `None`.
    *   **Truthy:** Any non-zero number, non-empty string, non-empty collection.
    ```python
    if []:
        print("Empty list is truthy") # This will NOT print
    else:
        print("Empty list is falsy")  # This will print
    ```

### 3. String Type (`str`)

*   **Definition:** An immutable sequence of Unicode characters. Used to represent text.
*   **Characteristics:**
    *   **Immutable:** Once created, a string's characters cannot be changed. Operations that seem to modify a string actually return a new string.
    *   **Ordered:** Characters maintain their order.
    *   **Indexed:** Each character can be accessed by its position (index), starting from `0`.
*   **Creation:** Enclosed in single quotes (`'...'`), double quotes (`"..."`), or triple quotes (`'''...'''` or `"""..."""`) for multi-line strings.
    ```python
    name = "Alice"
    message = 'Hello, world!'
    multi_line = """This is a
    multi-line string."""
    ```
*   **Common Operations:**
    *   **Concatenation:** `+` operator.
        ```python
        greeting = "Hello" + " " + name # "Hello Alice"
        ```
    *   **Repetition:** `*` operator.
        ```python
        dashes = "-" * 10 # "----------"
        ```
    *   **Indexing & Slicing:** Access specific characters or substrings.
        ```python
        s = "Python"
        print(s[0])       # 'P' (first character)
        print(s[-1])      # 'n' (last character)
        print(s[1:4])     # 'yth' (from index 1 up to but not including 4)
        print(s[2:])      # 'thon' (from index 2 to end)
        print(s[:3])      # 'Pyt' (from beginning up to but not including 3)
        print(s[::2])     # 'Pto' (every second character)
        ```
    *   **Length:** `len()` function.
        ```python
        print(len(name))  # 5
        ```
    *   **Methods:** Rich set of string methods for manipulation (e.g., `upper()`, `lower()`, `strip()`, `split()`, `join()`, `find()`, `replace()`, `startswith()`, `endswith()`).
        ```python
        text = "  Hello Python  "
        print(text.strip())       # "Hello Python"
        print(text.upper())       # "  HELLO PYTHON  "
        print("Py".join(["thon", "grammer"])) # "thonPygrammer"
        print("apple,banana,orange".split(',')) # ['apple', 'banana', 'orange']
        ```
    *   **f-strings (Formatted String Literals):** Powerful way to embed expressions inside string literals.
        ```python
        item = "Laptop"
        price = 1200
        print(f"The {item} costs ${price:.2f}.") # "The Laptop costs $1200.00."
        ```

### 4. List Type (`list`)

*   **Definition:** An ordered, mutable sequence of items. Items can be of different datatypes (heterogeneous).
*   **Characteristics:**
    *   **Mutable:** Elements can be added, removed, or changed after creation.
    *   **Ordered:** Elements maintain their insertion order.
    *   **Indexed:** Elements can be accessed by their position (index), starting from `0`.
    *   **Heterogeneous:** Can store elements of different types.
*   **Creation:** Enclosed in square brackets `[]`.
    ```python
    my_list = [1, "hello", 3.14, True]
    empty_list = []
    ```
*   **Common Operations:**
    *   **Indexing & Slicing:** Same as strings.
        ```python
        print(my_list[0])    # 1
        print(my_list[1:3])  # ['hello', 3.14]
        ```
    *   **Length:** `len()` function.
    *   **Adding Elements:**
        *   `append(item)`: Adds an item to the end.
        *   `insert(index, item)`: Inserts an item at a specific index.
        *   `extend(iterable)`: Appends all items from an iterable.
        ```python
        my_list.append(False) # [1, 'hello', 3.14, True, False]
        my_list.insert(1, "world") # [1, 'world', 'hello', 3.14, True, False]
        my_list.extend([10, 20]) # [1, 'world', 'hello', 3.14, True, False, 10, 20]
        ```
    *   **Removing Elements:**
        *   `remove(item)`: Removes the first occurrence of a specific item.
        *   `pop(index)`: Removes and returns the item at a specific index (defaults to last).
        *   `del list[index]` or `del list[slice]`: Deletes item(s) by index or slice.
        *   `clear()`: Removes all items.
        ```python
        my_list.remove("hello")
        popped_item = my_list.pop(0) # removes 1, popped_item = 1
        del my_list[1] # removes '3.14'
        ```
    *   **Changing Elements:** Direct assignment by index.
        ```python
        my_list[0] = "new_value" # ['new_value', True, False, 10, 20]
        ```
    *   **Concatenation:** `+` operator.
    *   **Repetition:** `*` operator.
    *   **Sorting:** `sort()` method (in-place) or `sorted()` function (returns new list).
        ```python
        numbers = [3, 1, 4, 1, 5]
        numbers.sort() # [1, 1, 3, 4, 5]
        sorted_numbers = sorted([5, 2, 8]) # [2, 5, 8]
        ```
    *   **Membership Test:** `in` operator.
        ```python
        print("new_value" in my_list) # True
        ```

### 5. Tuple Type (`tuple`)

*   **Definition:** An ordered, immutable sequence of items. Similar to lists but cannot be changed after creation.
*   **Characteristics:**
    *   **Immutable:** Elements cannot be added, removed, or changed after creation.
    *   **Ordered:** Elements maintain their insertion order.
    *   **Indexed:** Elements can be accessed by their position (index), starting from `0`.
    *   **Heterogeneous:** Can store elements of different types.
*   **Creation:** Enclosed in parentheses `()`, or simply by comma-separated values (tuple packing). A single-item tuple requires a trailing comma.
    ```python
    my_tuple = (1, "hello", 3.14)
    single_item_tuple = ("item",) # Note the comma!
    packed_tuple = 10, 20, "abc"
    empty_tuple = ()
    ```
*   **Common Operations:**
    *   **Indexing & Slicing:** Same as strings and lists.
    *   **Length:** `len()` function.
    *   **Concatenation:** `+` operator (returns a new tuple).
    *   **Repetition:** `*` operator (returns a new tuple).
    *   **Membership Test:** `in` operator.
    *   **`count()` and `index()` methods:** For counting occurrences and finding the first index of an element.
        ```python
        t = (1, 2, 2, 3, 1)
        print(t.count(1)) # 2
        print(t.index(3)) # 3
        ```
*   **Use Cases:**
    *   Returning multiple values from a function.
    *   Representing fixed collections of items (e.g., coordinates, RGB colors).
    *   As dictionary keys (because they are immutable) or elements in sets (if all elements within the tuple are also immutable).

### 6. Set Type (`set`)

*   **Definition:** An unordered collection of unique and immutable items. Used for storing distinct items.
*   **Characteristics:**
    *   **Mutable:** The set itself can be changed (elements added/removed), but the elements *within* the set must be immutable (hashable).
    *   **Unordered:** Elements do not have a defined order; no indexing or slicing.
    *   **Unique Elements:** Duplicate elements are automatically removed.
    *   **Heterogeneous (with immutable types):** Can store different types of immutable elements.
*   **Creation:** Enclosed in curly braces `{}` or using the `set()` constructor. An empty set *must* be created with `set()`, as `{}` creates an empty dictionary.
    ```python
    my_set = {1, 2, 3, 1} # {1, 2, 3} - duplicates removed
    another_set = {"apple", "banana"}
    empty_set = set()
    # my_set_invalid = {[1,2], 3} # Error: list is mutable, cannot be in a set
    ```
*   **Common Operations:**
    *   **Adding Elements:** `add(item)`.
    *   **Removing Elements:** `remove(item)` (raises `KeyError` if item not found), `discard(item)` (does not raise error), `pop()` (removes and returns an arbitrary element), `clear()`.
        ```python
        my_set.add(4) # {1, 2, 3, 4}
        my_set.remove(1) # {2, 3, 4}
        ```
    *   **Membership Test:** `in` operator (very efficient).
    *   **Set Operations (mathematical sets):**
        *   `union()` or `|`: All unique elements from both sets.
        *   `intersection()` or `&`: Common elements in both sets.
        *   `difference()` or `-`: Elements in the first set but not the second.
        *   `symmetric_difference()` or `^`: Elements in either set, but not both.
        *   `issubset()`, `issuperset()`, `isdisjoint()`.
        ```python
        set1 = {1, 2, 3}
        set2 = {3, 4, 5}
        print(set1 | set2) # {1, 2, 3, 4, 5} (union)
        print(set1 & set2) # {3} (intersection)
        print(set1 - set2) # {1, 2} (difference)
        ```
*   **Use Cases:**
    *   Efficiently checking for membership.
    *   Removing duplicate items from a list.
    *   Performing mathematical set operations.

#### Frozenset Type (`frozenset`)
*   **Definition:** An immutable version of a `set`.
*   **Characteristics:**
    *   **Immutable:** Cannot be changed after creation.
    *   **Hashable:** Because it's immutable, a `frozenset` can be an element of another set or a key in a dictionary.
*   **Creation:** Using the `frozenset()` constructor.
    ```python
    fs = frozenset([1, 2, 3])
    # fs.add(4) # Error: 'frozenset' object has no attribute 'add'
    ```
*   **Use Cases:** When you need a set-like object that can be stored in other collections requiring hashable elements.

### 7. Dictionary Type (`dict`)

*   **Definition:** An unordered (in versions prior to Python 3.7; ordered by insertion in 3.7+), mutable collection of key-value pairs.
*   **Characteristics:**
    *   **Mutable:** Key-value pairs can be added, removed, or changed.
    *   **Keys must be unique and immutable (hashable):** Common key types are strings, numbers, and tuples. Lists and sets cannot be keys.
    *   **Values can be of any type:** Can be heterogeneous.
    *   **Access by Key:** Not by numerical index.
    *   **Ordered by Insertion (Python 3.7+):** Dictionaries remember the order in which items were inserted.
*   **Creation:** Enclosed in curly braces `{}` with `key: value` pairs.
    ```python
    person = {"name": "Alice", "age": 30, "city": "New York"}
    empty_dict = {}
    ```
*   **Common Operations:**
    *   **Accessing Values:** Using square bracket notation `dict[key]` (raises `KeyError` if key not found) or `dict.get(key, default_value)` (returns `None` or `default_value` if key not found).
        ```python
        print(person["name"])    # Alice
        print(person.get("age")) # 30
        print(person.get("country", "USA")) # USA (default value)
        ```
    *   **Adding/Modifying Values:** Assign a value to a key.
        ```python
        person["occupation"] = "Engineer" # Add new key-value pair
        person["age"] = 31               # Modify existing value
        ```
    *   **Removing Values:** `del dict[key]`, `pop(key)`, `popitem()` (removes and returns an arbitrary/last (3.7+) key-value pair), `clear()`.
        ```python
        del person["city"]
        occupation = person.pop("occupation") # Removes and returns 'Engineer'
        ```
    *   **Length:** `len()` function.
    *   **Methods:**
        *   `keys()`: Returns a view object of all keys.
        *   `values()`: Returns a view object of all values.
        *   `items()`: Returns a view object of all key-value pairs (as tuples).
        *   `update(other_dict)`: Merges another dictionary into this one.
        ```python
        print(person.keys())   # dict_keys(['name', 'age'])
        print(person.values()) # dict_values(['Alice', 31])
        print(person.items())  # dict_items([('name', 'Alice'), ('age', 31)])

        person.update({"city": "London", "age": 32})
        # {'name': 'Alice', 'age': 32, 'city': 'London'}
        ```
    *   **Membership Test:** `in` operator (checks for keys, not values).
        ```python
        print("name" in person) # True
        print("Alice" in person) # False (checks only keys)
        ```
*   **Use Cases:**
    *   Storing structured data where elements are identified by unique keys (e.g., JSON-like data).
    *   Implementing hash maps or associative arrays.

### 8. None Type (`NoneType`)

*   **Definition:** Represents the absence of a value, a null value, or an undefined value.
*   **Characteristics:**
    *   **Singleton:** There is only one `None` object in Python. All `None` references point to the same object.
    *   **Immutable:** `None` cannot be changed.
    *   **Falsy:** Evaluates to `False` in a boolean context.
*   **Creation:** The keyword `None`.
    ```python
    result = None
    ```
*   **Use Cases:**
    *   Default argument values indicating no value has been provided.
    *   Functions that don't explicitly `return` a value implicitly return `None`.
    *   Initializing variables that will hold a value later.
    *   Comparing with `is None` (identity check, preferred over `== None`).
    ```python
    def my_function(data):
        if data is None:
            print("No data provided.")
        else:
            print(f"Processing data: {data}")

    my_function(None) # No data provided.
    my_function("some_data") # Processing data: some_data
    ```

### 9. Bytes and Bytearray Types (`bytes`, `bytearray`)

*   **Definition:** Represent sequences of bytes (raw binary data). Each element is an integer in the range `0` to `255`.
*   **`bytes` (`bytes` type):**
    *   **Immutable:** Cannot be changed after creation.
    *   **Creation:** Prefixing a string literal with `b` or using the `bytes()` constructor.
        ```python
        b_string = b"hello"
        byte_data = bytes([72, 101, 108, 108, 111]) # ASCII for 'hello'
        ```
*   **`bytearray` (`bytearray` type):**
    *   **Mutable:** Elements can be changed, added, or removed.
    *   **Creation:** Using the `bytearray()` constructor.
        ```python
        ba_data = bytearray(b"world")
        ba_data[0] = 87 # Change 'w' to 'W' (ASCII 87)
        print(ba_data) # bytearray(b'World')
        ```
*   **Common Operations:** Indexing, slicing, concatenation, iteration. Similar to strings but operate on bytes.
    *   **Encoding/Decoding:** Crucial for converting between strings (Unicode) and bytes (specific encoding like UTF-8).
        ```python
        s = "Hello World"
        encoded_s = s.encode('utf-8') # bytes object
        print(encoded_s) # b'Hello World'
        decoded_s = encoded_s.decode('utf-8') # string object
        print(decoded_s) # Hello World
        ```
*   **Use Cases:**
    *   Handling binary files (images, audio).
    *   Network communication (sockets).
    *   Cryptographic operations.
    *   Working with low-level data.

### 10. Range Type (`range`)

*   **Definition:** Represents an immutable sequence of numbers, commonly used for looping a specific number of times in `for` loops.
*   **Characteristics:**
    *   **Immutable:** The sequence cannot be changed.
    *   **Memory-efficient:** It doesn't store all the numbers in memory but generates them on the fly.
    *   **Lazy Evaluation:** Numbers are generated only when needed.
*   **Creation:** Using the `range()` constructor.
    *   `range(stop)`: Generates numbers from `0` up to (but not including) `stop`.
    *   `range(start, stop)`: Generates numbers from `start` up to (but not including) `stop`.
    *   `range(start, stop, step)`: Generates numbers from `start` up to (but not including) `stop`, incrementing by `step`.
    ```python
    r1 = range(5)          # 0, 1, 2, 3, 4
    r2 = range(1, 6)       # 1, 2, 3, 4, 5
    r3 = range(0, 10, 2)   # 0, 2, 4, 6, 8
    ```
*   **Use Cases:**
    ```python
    for i in range(3):
        print(i) # 0, 1, 2

    # Convert to list to see elements (not usually done in practice for large ranges)
    print(list(range(5))) # [0, 1, 2, 3, 4]
    ```

### Summary of Key Concepts

*   **Dynamic Typing:** Python determines types at runtime, not compile time.
*   **Mutability:** The ability of an object to be changed after creation. Crucial for understanding how Python handles data and memory.
    *   **Mutable:** `list`, `dict`, `set`, `bytearray`
    *   **Immutable:** `int`, `float`, `complex`, `bool`, `str`, `tuple`, `frozenset`, `bytes`, `range`, `NoneType`
*   **Collections:** Datatypes that can hold multiple items (e.g., lists, tuples, sets, dictionaries).
*   **Ordered vs. Unordered:** Whether items maintain their insertion order and can be accessed by index.
    *   **Ordered:** `list`, `tuple`, `str`, `range`, `bytes`, `bytearray`, `dict` (since Python 3.7)
    *   **Unordered:** `set`, `dict` (prior to Python 3.7)
*   **`type()` vs. `isinstance()`:**
    *   `type(obj)`: Returns the exact type of an object.
    *   `isinstance(obj, classinfo)`: Checks if an object is an instance of a class or a subclass thereof. Generally preferred for type checking, as it handles inheritance.
        ```python
        class MyInt(int): pass
        x = MyInt(10)
        print(type(x) == int)      # False
        print(isinstance(x, int))  # True (because MyInt is a subclass of int)
        ```

Understanding these core datatypes and their characteristics is fundamental to writing effective and efficient Python code.
