# Python: Detailed Notes

## 1. Introduction to Python

*   **What is Python?**
    *   High-level, interpreted, general-purpose programming language.
    *   Created by Guido van Rossum, first released in 1991.
    *   Emphasizes readability with its clear and concise syntax (significant indentation).
*   **Key Features:**
    *   **Simple & Readable:** Syntax similar to natural language.
    *   **Interpreted:** Code is executed line by line, no compilation step (though `.pyc` bytecode is generated).
    *   **Dynamically Typed:** Variable types are determined at runtime.
    *   **High-level:** Abstracts away low-level details like memory management.
    *   **Cross-platform:** Runs on Windows, macOS, Linux, etc.
    *   **Object-Oriented:** Supports classes, objects, inheritance, etc.
    *   **Extensible:** Can be extended with modules written in C/C++.
    *   **Large Standard Library:** Rich set of modules for various tasks (OS interaction, networking, math, etc.).
    *   **Community Support:** Vast and active community.
*   **Python 2 vs. Python 3:**
    *   Python 3 is the current and actively developed version.
    *   Python 2 reached End-of-Life in 2020 and should not be used for new projects.
    *   Key differences include `print` (function in P3, statement in P2), integer division, Unicode handling, etc.
*   **Installation:**
    *   Download from `python.org`.
    *   Often pre-installed on Linux/macOS.
    *   Use `pip` (Python's package installer) to install third-party libraries.
        ```bash
        python -m pip install <package_name>
        ```
*   **Basic Syntax:**
    *   **Comments:** `# single-line`, `"""multi-line string literal"""`
    *   **Indentation:** Uses whitespace (4 spaces is PEP 8 standard) to define code blocks, not curly braces.
    *   **First Program:**
        ```python
        print("Hello, Python!")
        ```

## 2. Variables and Data Types

*   **Variables:**
    *   Names given to memory locations to store data.
    *   No explicit type declaration needed (dynamic typing).
    *   Assignment: `variable_name = value`
    *   Rules: Start with letter/underscore, can contain numbers, case-sensitive.
*   **Built-in Data Types:**

    *   **A. Numeric Types:**
        *   `int`: Integers (e.g., `10`, `-5`, `1_000_000`)
        *   `float`: Floating-point numbers (e.g., `3.14`, `-0.5`, `2.0`)
        *   `complex`: Complex numbers (e.g., `1 + 2j`)

    *   **B. Boolean Type:**
        *   `bool`: Represents truth values (`True` or `False`).

    *   **C. Sequence Types (Ordered, Indexable):**
        *   `str`: Strings (immutable sequence of characters).
            ```python
            name = "Alice"
            message = 'Hello World'
            multi_line = """This is a
            multi-line string."""
            # Operations: concatenation (+), repetition (*), slicing, len(), in
            ```
        *   `list`: Lists (mutable, ordered sequence of items, `[]`).
            ```python
            my_list = [1, "hello", 3.14, True]
            # Methods: append(), insert(), remove(), pop(), sort(), reverse()
            ```
        *   `tuple`: Tuples (immutable, ordered sequence of items, `()`).
            ```python
            my_tuple = (1, "hello", 3.14)
            # Cannot change elements after creation. Faster than lists for fixed data.
            ```

    *   **D. Set Types (Unordered, Unique Elements):**
        *   `set`: Sets (mutable, unordered collection of unique items, `{}` or `set()`).
            ```python
            my_set = {1, 2, 3, 2} # Result: {1, 2, 3}
            # Operations: union (|), intersection (&), difference (-), add(), remove()
            ```
        *   `frozenset`: Immutable version of set.

    *   **E. Mapping Type (Key-Value Pairs):**
        *   `dict`: Dictionaries (mutable, unordered collection of key-value pairs, `{}`). Keys must be unique and immutable.
            ```python
            person = {"name": "Bob", "age": 30, "city": "New York"}
            # Access: person["name"]
            # Methods: keys(), values(), items(), get(), update(), pop()
            ```

*   **Type Conversion (Type Casting):**
    *   Use built-in functions: `int()`, `float()`, `str()`, `list()`, `tuple()`, `set()`, `dict()`.
    ```python
    num_str = "123"
    num_int = int(num_str) # 123
    ```

## 3. Operators

*   **Arithmetic Operators:** `+`, `-`, `*`, `/` (float division), `//` (integer division), `%` (modulo), `**` (exponentiation).
*   **Comparison Operators:** `==` (equal to), `!=` (not equal to), `>` (greater than), `<` (less than), `>=` (greater than or equal to), `<=` (less than or equal to).
*   **Logical Operators:**
    *   `and`: Returns `True` if both operands are `True`.
    *   `or`: Returns `True` if at least one operand is `True`.
    *   `not`: Reverses the boolean value.
*   **Assignment Operators:** `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`, `//=`.
*   **Identity Operators:**
    *   `is`: Returns `True` if two variables point to the *same object* in memory.
    *   `is not`: Returns `True` if two variables point to *different objects*.
*   **Membership Operators:**
    *   `in`: Returns `True` if a value is found in a sequence.
    *   `not in`: Returns `True` if a value is not found in a sequence.
*   **Bitwise Operators:** `&` (AND), `|` (OR), `^` (XOR), `~` (NOT), `<<` (left shift), `>>` (right shift). (Less common in typical high-level Python).

## 4. Control Flow

*   **Conditional Statements (`if`, `elif`, `else`):**
    ```python
    age = 25
    if age < 18:
        print("Minor")
    elif 18 <= age < 65:
        print("Adult")
    else:
        print("Senior")
    ```
*   **Loops:**
    *   **`for` loop (Iterating over sequences):**
        ```python
        for item in [1, 2, 3]:
            print(item)

        for i in range(5): # 0, 1, 2, 3, 4
            print(i)

        # enumerate: for index and value
        for index, char in enumerate("Python"):
            print(f"{index}: {char}")

        # zip: for parallel iteration
        names = ["Alice", "Bob"]
        ages = [25, 30]
        for name, age in zip(names, ages):
            print(f"{name} is {age} years old.")
        ```
    *   **`while` loop (Loop until condition is false):**
        ```python
        count = 0
        while count < 3:
            print(count)
            count += 1
        ```
*   **Loop Control Statements:**
    *   `break`: Terminates the loop entirely.
    *   `continue`: Skips the rest of the current iteration and moves to the next.
    *   `pass`: A null operation; used as a placeholder where a statement is syntactically required but you want to do nothing.

## 5. Functions

*   **Definition:** Reusable blocks of code to perform a specific task.
*   **Syntax:**
    ```python
    def function_name(parameter1, parameter2=default_value):
        """Docstring: Explain what the function does."""
        # Function body
        return result # Optional: returns a value
    ```
*   **Calling a Function:** `function_name(argument1, argument2)`
*   **Arguments:**
    *   **Positional Arguments:** Passed in order.
    *   **Keyword Arguments:** Passed by name (`param=value`).
    *   **Default Arguments:** Parameters with default values if not provided.
    *   **Arbitrary Arguments (`*args`, `**kwargs`):**
        *   `*args`: Collects positional arguments into a tuple.
        *   `**kwargs`: Collects keyword arguments into a dictionary.
        ```python
        def my_sum(*numbers):
            return sum(numbers)

        def greet_person(**details):
            print(f"Hello {details['name']} from {details['city']}")
        ```
*   **Return Statement:** `return` keyword sends a value back to the caller. If omitted, `None` is returned implicitly.
*   **Scope:**
    *   **LEGB Rule:** Local, Enclosing function locals, Global, Built-in.
    *   `global` keyword: Used to modify a global variable from inside a function.
    *   `nonlocal` keyword: Used to modify a variable in an enclosing (non-global) scope.
*   **Lambda Functions (Anonymous Functions):**
    *   Small, single-expression functions.
    *   Syntax: `lambda arguments: expression`
    ```python
    add = lambda x, y: x + y
    print(add(5, 3)) # Output: 8
    ```
*   **Docstrings:** Strings used to document modules, classes, functions, and methods. Accessed via `__doc__` or `help()`.

## 6. Object-Oriented Programming (OOP)

*   **Concepts:**
    *   **Class:** A blueprint for creating objects (e.g., `Car` class).
    *   **Object (Instance):** An instance of a class (e.g., `my_car = Car("Toyota")`).
    *   **Attribute:** A variable associated with a class or object (e.g., `Car.color`, `my_car.speed`).
    *   **Method:** A function associated with a class or object (e.g., `my_car.accelerate()`).
    *   **Encapsulation:** Bundling data (attributes) and methods that operate on the data within a single unit (class).
    *   **Inheritance:** A mechanism for a new class (child/derived) to inherit attributes and methods from an existing class (parent/base).
    *   **Polymorphism:** The ability of different objects to respond to the same method call in their own specific ways.
    *   **Abstraction:** Hiding complex implementation details and showing only essential features.
*   **Defining a Class:**
    ```python
    class MyClass:
        # Class attributes (shared by all instances)
        class_attribute = "I am a class attribute"

        def __init__(self, param1, param2):
            # Constructor method, called when a new object is created.
            # 'self' refers to the instance being created.
            self.instance_attribute1 = param1
            self.instance_attribute2 = param2

        def instance_method(self):
            # Instance method: operates on instance attributes.
            return f"Hello from {self.instance_attribute1}"

        @classmethod
        def class_method(cls, arg):
            # Class method: operates on class attributes, receives the class itself (cls).
            return f"Class attribute: {cls.class_attribute}, Arg: {arg}"

        @staticmethod
        def static_method(arg):
            # Static method: utility method, doesn't access instance or class.
            return f"Static method called with {arg}"

    # Creating an object
    obj = MyClass("Value1", "Value2")
    print(obj.instance_attribute1)
    print(obj.instance_method())
    print(MyClass.class_method("test")) # Call class method via class
    print(obj.static_method(123))       # Call static method via instance or class
    ```
*   **Inheritance:**
    ```python
    class Animal:
        def __init__(self, name):
            self.name = name
        def speak(self):
            raise NotImplementedError("Subclass must implement abstract method")

    class Dog(Animal):
        def speak(self):
            return f"{self.name} says Woof!"

    class Cat(Animal):
        def speak(self):
            return f"{self.name} says Meow!"

    my_dog = Dog("Buddy")
    my_cat = Cat("Whiskers")
    print(my_dog.speak())
    print(my_cat.speak())
    ```
    *   `super()`: Used to call a method from the parent class.
*   **Special/Magic/Dunder Methods:**
    *   Methods with `__` prefix and suffix (e.g., `__init__`, `__str__`, `__repr__`, `__len__`, `__add__`).
    *   Used to define how objects behave in certain situations (e.g., string representation, arithmetic operations).
    *   `__str__`: User-friendly string representation (called by `str()` and `print()`).
    *   `__repr__`: Unambiguous string representation (for developers, used in interactive console).

## 7. Modules and Packages

*   **Modules:** Python files (`.py`) containing definitions (functions, classes, variables). Used to organize code.
*   **Packages:** Collections of modules in directories, often with an `__init__.py` file (though not strictly required in Python 3.3+ for simple packages).
*   **Importing:**
    ```python
    # my_module.py
    def greet(name):
        return f"Hello, {name}!"

    PI = 3.14159

    # main.py
    import my_module
    print(my_module.greet("Alice"))
    print(my_module.PI)

    from my_module import greet, PI
    print(greet("Bob"))
    print(PI)

    from my_module import * # Imports all (not recommended for production)

    import my_module as mm # Alias
    print(mm.greet("Charlie"))
    ```
*   **Standard Library:** Python comes with many built-in modules.
    *   `math`: Mathematical functions.
    *   `random`: Generate random numbers.
    *   `os`: Interact with the operating system.
    *   `sys`: System-specific parameters and functions.
    *   `datetime`: Date and time manipulation.
    *   `json`: Working with JSON data.
    *   `re`: Regular expressions.
*   **Third-Party Packages:** Installed using `pip` (e.g., `requests`, `numpy`, `pandas`, `django`, `flask`).

## 8. File I/O (Input/Output)

*   **Opening Files:** `open(filename, mode)`
    *   `mode`:
        *   `'r'`: Read (default).
        *   `'w'`: Write (truncates file if exists, creates if not).
        *   `'a'`: Append (adds to end of file, creates if not).
        *   `'x'`: Exclusive creation (fails if file exists).
        *   `'b'`: Binary mode (e.g., `'rb'`, `'wb'`).
        *   `'t'`: Text mode (default).
        *   `'+'`: Open for updating (e.g., `'r+'` for read/write).
*   **Reading from Files:**
    ```python
    with open("my_file.txt", "r") as f:
        content = f.read()          # Reads entire file
        line = f.readline()         # Reads one line
        lines = f.readlines()       # Reads all lines into a list
        # Iterate line by line (memory efficient for large files)
        for line in f:
            print(line.strip()) # .strip() removes leading/trailing whitespace
    ```
*   **Writing to Files:**
    ```python
    with open("my_output.txt", "w") as f:
        f.write("Hello, Python!\n")
        f.write("This is a new line.")

    # Appending
    with open("my_output.txt", "a") as f:
        f.write("\nAppending more content.")
    ```
*   **`with` Statement (Context Manager):**
    *   **Recommended practice.** Ensures files are automatically closed, even if errors occur.
    *   Prevents resource leaks.

## 9. Error and Exception Handling

*   **Errors vs. Exceptions:**
    *   **Syntax Errors:** Occur before execution (e.g., missing colon, incorrect indentation).
    *   **Exceptions:** Occur during execution (runtime errors).
*   **Common Built-in Exceptions:**
    *   `TypeError`: Operation on incorrect type.
    *   `ValueError`: Function receives an argument of correct type but inappropriate value.
    *   `NameError`: Variable not defined.
    *   `IndexError`: Index out of range for a sequence.
    *   `KeyError`: Key not found in dictionary.
    *   `FileNotFoundError`: File not found.
    *   `ZeroDivisionError`: Division by zero.
    *   `AttributeError`: Attempt to access an invalid attribute.
*   **`try`, `except`, `else`, `finally` Block:**
    ```python
    try:
        # Code that might raise an exception
        result = 10 / 0
    except ZeroDivisionError:
        # Handle a specific exception
        print("Cannot divide by zero!")
    except TypeError as e:
        # Handle another specific exception, capture error message
        print(f"Type error: {e}")
    except Exception as e:
        # Catch any other exception (general handler, less specific)
        print(f"An unexpected error occurred: {e}")
    else:
        # Code to execute if no exception occurred in the 'try' block
        print("No error occurred, result:", result)
    finally:
        # Code to execute always, regardless of exceptions
        print("Execution finished.")
    ```
*   **`raise` Statement:**
    *   Used to explicitly raise an exception.
    *   `raise ValueError("Invalid input provided")`
*   **Custom Exceptions:**
    *   Define by inheriting from `Exception` class.
    ```python
    class MyCustomError(Exception):
        def __init__(self, message="A custom error occurred"):
            self.message = message
            super().__init__(self.message)

    # raise MyCustomError("Something specific went wrong!")
    ```

## 10. Advanced Topics (Brief Overview)

*   **List, Dictionary, Set Comprehensions:**
    *   Concise ways to create lists, dictionaries, or sets.
    ```python
    squares = [x**2 for x in range(10) if x % 2 == 0] # [0, 4, 16, 36, 64]
    square_dict = {x: x**2 for x in range(5)} # {0:0, 1:1, 2:4, 3:9, 4:16}
    ```
*   **Generators:**
    *   Functions that produce a sequence of results one at a time using `yield`.
    *   Memory efficient for large sequences as they don't store the entire sequence in memory.
    ```python
    def count_up_to(n):
        i = 0
        while i <= n:
            yield i
            i += 1

    for num in count_up_to(5):
        print(num)
    ```
*   **Decorators (`@` syntax):**
    *   Functions that take another function as an argument, add some functionality, and return a new function.
    *   Used for logging, timing, authentication, etc.
    ```python
    def my_decorator(func):
        def wrapper(*args, **kwargs):
            print("Before function call")
            result = func(*args, **kwargs)
            print("After function call")
            return result
        return wrapper

    @my_decorator
    def say_hello(name):
        print(f"Hello, {name}!")

    say_hello("Alice")
    ```
*   **Iterators:**
    *   Objects that implement the `__iter__()` and `__next__()` methods.
    *   Enable iteration over custom objects.
*   **Context Managers:**
    *   Objects that support the `with` statement, implementing `__enter__()` and `__exit__()`.
    *   Ensure proper setup and teardown of resources (like file handling).
    *   Can be created using classes or `contextlib.contextmanager` decorator.
*   **Concurrency (`threading`, `multiprocessing`):**
    *   `threading`: For I/O-bound tasks. Subject to Python's Global Interpreter Lock (GIL), meaning only one thread can execute Python bytecode at a time.
    *   `multiprocessing`: For CPU-bound tasks. Spawns new processes, bypassing the GIL.
*   **Asynchronous Programming (`async`/`await`):**
    *   `asyncio` module for concurrent execution of I/O-bound operations using coroutines.
    *   Allows a single thread to manage multiple I/O operations efficiently.

## 11. Best Practices and Tools

*   **PEP 8:** Python Enhancement Proposal 8 – Style Guide for Python Code. Adhering to it improves readability and consistency.
    *   4 spaces for indentation.
    *   Max line length of 79 characters.
    *   Use meaningful variable names.
    *   Blank lines to separate logical sections.
*   **Virtual Environments (`venv`, `conda`):**
    *   Isolate project dependencies to avoid conflicts.
    *   `python -m venv myenv`
    *   `source myenv/bin/activate` (Linux/macOS) or `myenv\Scripts\activate` (Windows)
*   **Testing (`unittest`, `pytest`):**
    *   Writing tests to ensure code works as expected and prevent regressions.
*   **Debugging (`pdb`):**
    *   Python Debugger. `import pdb; pdb.set_trace()`
*   **Version Control (`Git`):**
    *   Essential for tracking changes and collaboration.
*   **Documentation:**
    *   Use docstrings for modules, classes, functions.
    *   Tools like Sphinx for generating comprehensive documentation.
