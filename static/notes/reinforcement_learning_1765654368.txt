Reinforcement Learning (RL) is a paradigm of machine learning where an **agent** learns to make decisions by interacting with an **environment**. The goal of the agent is to learn a **policy** that maximizes the **cumulative reward** it receives over time.

---

### I. Core Concepts & Terminology

1.  **Agent:** The learner and decision-maker. It observes the environment and takes actions.
2.  **Environment:** The external system with which the agent interacts. It receives actions from the agent and transitions to a new state, providing a reward.
3.  **State (S):** A complete description of the environment at a specific time.
4.  **Action (A):** A move or decision made by the agent within a given state.
5.  **Reward (R):** A scalar feedback signal from the environment to the agent, indicating the desirability of the agent's last action in a given state. The agent's ultimate goal is to maximize cumulative reward.
6.  **Policy ($\pi$):** The agent's strategy, which maps states to actions. It defines the agent's behavior. A deterministic policy is $\pi(s) = a$, while a stochastic policy is $\pi(a|s)$, giving the probability of taking action 'a' in state 's'.
7.  **Value Function (V):** A prediction of the expected cumulative future reward starting from a given state and following a particular policy. $V_{\pi}(s) = E_{\pi}[\sum_{t=0}^{\infty} \gamma^t R_{t+1} | S_0=s]$
8.  **Action-Value Function (Q):** Similar to the value function, but it predicts the expected cumulative future reward for taking a specific action 'a' in a specific state 's' and then following a particular policy thereafter. $Q_{\pi}(s,a) = E_{\pi}[\sum_{t=0}^{\infty} \gamma^t R_{t+1} | S_0=s, A_0=a]$
9.  **Model (of the environment, optional):** The agent's internal representation of how the environment behaves. It predicts the next state and reward given a current state and action.
10. **Discount Factor ($\gamma$):** A value between 0 and 1 (typically 0.9 to 0.999) that determines the present value of future rewards. A higher $\gamma$ means the agent considers future rewards more heavily.

---

### II. The RL Problem: Markov Decision Process (MDP)

Most RL problems are formalized as **Markov Decision Processes (MDPs)**. An MDP is defined by a 5-tuple: $(S, A, P, R, \gamma)$.

*   **S:** A finite set of states.
*   **A:** A finite set of actions.
*   **P:** A state transition probability function $P(s'|s,a)$, which gives the probability of transitioning to state $s'$ from state $s$ after taking action $a$.
*   **R:** A reward function $R(s,a,s')$, giving the reward received after transitioning from state $s$ to $s'$ via action $a$.
*   **$\gamma$:** The discount factor.

**Markov Property:** The future is conditionally independent of the past given the present state. i.e., $P(S_{t+1}|S_t, A_t, S_{t-1}, A_{t-1}, ...) = P(S_{t+1}|S_t, A_t)$.

**Goal:** Find an **optimal policy ($\pi^*$)** that maximizes the expected cumulative discounted reward. This means finding $\pi^*$ such that $V_{\pi^*}(s) \ge V_{\pi}(s)$ for all $s$ and all $\pi$.

**Bellman Equations:** These are fundamental equations that relate the value of a state or state-action pair to the values of successor states/actions. They form the basis for many RL algorithms.

*   **Bellman Expectation Equation (for $V_{\pi}$):**
    $V_{\pi}(s) = \sum_a \pi(a|s) \sum_{s', r} P(s',r|s,a) [r + \gamma V_{\pi}(s')]$
*   **Bellman Optimality Equation (for $V_{\pi^*}$):**
    $V_{\pi^*}(s) = \max_a \sum_{s', r} P(s',r|s,a) [r + \gamma V_{\pi^*}(s')]$
*   Similar equations exist for $Q_{\pi}(s,a)$ and $Q_{\pi^*}(s,a)$.

### III. Types of RL Algorithms

#### A. Based on Environment Model

1.  **Model-Based RL:**
    *   The agent learns or is given a model of the environment (P and R functions).
    *   It can then use this model to plan (e.g., with Dynamic Programming or Monte Carlo Tree Search) without direct interaction with the real environment.
    *   Examples: Value Iteration, Policy Iteration.

2.  **Model-Free RL:**
    *   The agent learns directly from experience (trial and error) without explicitly building a model of the environment.
    *   More common for complex, unknown environments.
    *   Examples: Q-Learning, SARSA, Policy Gradients.

#### B. Based on Learning Approach

1.  **Value-Based Methods:**
    *   Learn the optimal value function ($V^*$ or $Q^*$).
    *   The policy is then derived from the value function (e.g., by choosing the action that leads to the highest Q-value).
    *   Examples: Q-Learning, SARSA, Deep Q-Networks (DQN).

2.  **Policy-Based Methods:**
    *   Directly learn the optimal policy $\pi^*$ without explicitly learning a value function.
    *   Often parameterize the policy with a neural network and use gradient ascent to optimize the policy parameters.
    *   Better for continuous action spaces.
    *   Examples: REINFORCE, Actor-Critic methods.

3.  **Actor-Critic Methods:**
    *   Combine both value-based and policy-based approaches.
    *   **Actor:** Learns the policy (policy-based).
    *   **Critic:** Learns the value function (value-based) to evaluate the actor's actions and guide policy updates.
    *   Examples: A2C, A3C, PPO, DDPG, TD3.

#### C. Based on Policy Update

1.  **On-Policy:**
    *   The agent learns about the policy *it is currently following*.
    *   The policy used for *acting* (generating data) is the same as the policy being *evaluated and improved*.
    *   Examples: SARSA, REINFORCE, A2C/A3C.

2.  **Off-Policy:**
    *   The agent learns about an optimal policy *independently of the policy it is currently following* to generate data.
    *   Allows learning from "old" or "demonstration" data. More sample efficient.
    *   Examples: Q-Learning, DQN, DDPG, TD3.

### IV. Key Algorithms (Examples)

1.  **Dynamic Programming (Value Iteration, Policy Iteration):** Model-based. Requires full knowledge of the MDP. Solves for the optimal policy iteratively.

2.  **Monte Carlo (MC):** Model-free, value-based. Learns from complete episodes. Averages returns after each state-action visit. Suffers from high variance.

3.  **Temporal Difference (TD) Learning:** Model-free, value-based. Learns from partial episodes (bootstrapping). Updates estimates based on other learned estimates, not just actual final rewards.
    *   **SARSA (State-Action-Reward-State-Action):** On-policy TD control. Updates $Q(s,a)$ based on $Q(s',a')$ where $a'$ is the action *taken* in $s'$.
    *   **Q-Learning:** Off-policy TD control. Updates $Q(s,a)$ based on $\max_{a'} Q(s',a')$, meaning it learns the optimal Q-values regardless of the exploration policy. This is a very common and powerful algorithm.

4.  **Deep Reinforcement Learning (DRL):** Combines RL with deep neural networks to handle high-dimensional state/action spaces.
    *   **Deep Q-Networks (DQN):** Uses a deep neural network to approximate the Q-function. Introduced key techniques like **experience replay** (to break correlations in training data) and **target networks** (to stabilize training).
    *   **Policy Gradient Methods (e.g., REINFORCE):** Directly learn a parameterized policy using gradient ascent on the expected return.
    *   **Actor-Critic Methods (e.g., A2C, A3C, PPO, DDPG):** Use an actor (policy network) and a critic (value network) to estimate and update the policy. A3C is asynchronous, PPO (Proximal Policy Optimization) is a popular, robust, and performant algorithm.

### V. Challenges & Considerations

1.  **Exploration-Exploitation Dilemma:** The agent must balance exploring new actions to find better rewards (exploration) with exploiting known actions that yield high rewards (exploitation). Common strategies include $\epsilon$-greedy, softmax, or intrinsic motivation.
2.  **Credit Assignment Problem:** It can be hard to determine which actions over a sequence led to a particular reward, especially if rewards are sparse and delayed.
3.  **Curse of Dimensionality:** State and action spaces can become too large for traditional tabular methods. Deep learning helps address this.
4.  **Reward Shaping:** Designing effective reward functions can be challenging but crucial for learning.
5.  **Hyperparameter Tuning:** RL algorithms are often very sensitive to hyperparameters (learning rate, discount factor, $\epsilon$, etc.).
6.  **Non-Stationarity:** When the policy is updated, the target values for Q-functions also change, leading to a non-stationary target problem.

### VI. Applications

*   **Game Playing:** Mastering complex games like Go (AlphaGo), Chess, Atari games, StarCraft II.
*   **Robotics:** Learning control policies for manipulation, locomotion, and navigation.
*   **Autonomous Driving:** Decision-making for self-driving cars.
*   **Resource Management:** Optimizing energy grids, data centers, or network traffic.
*   **Personalized Recommendations:** Learning user preferences for content or products.
*   **Financial Trading:** Developing strategies for stock trading.
*   **Healthcare:** Optimizing treatment plans.
