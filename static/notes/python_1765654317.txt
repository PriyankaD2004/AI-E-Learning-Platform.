# Python Notes

## 1. Introduction to Python

*   **What is Python?**
    *   High-level, interpreted, general-purpose programming language.
    *   Created by Guido van Rossum, first released in 1991.
    *   Emphasizes code readability with its notable use of significant indentation.
    *   **Philosophy:** "Beautiful is better than ugly," "Simple is better than complex."
*   **Key Features:**
    *   **Easy to Learn:** Simple syntax, resembles natural language.
    *   **Interpreted:** Code is executed line by line, no compilation step (mostly).
    *   **High-level:** Don't need to manage memory directly.
    *   **Dynamically Typed:** Variable types are determined at runtime.
    *   **Cross-platform:** Runs on Windows, macOS, Linux, etc.
    *   **Extensible:** Can integrate with C/C++, Java.
    *   **Extensive Standard Library:** Built-in modules for many tasks.
    *   **Large Community:** Abundant resources, libraries (PyPI).
*   **Common Use Cases:**
    *   Web Development (Django, Flask)
    *   Data Science & Machine Learning (NumPy, Pandas, Scikit-learn, TensorFlow, PyTorch)
    *   Automation & Scripting
    *   Scientific Computing
    *   Desktop GUIs (Tkinter, PyQt)
    *   Game Development (Pygame)

## 2. Setup & Running Python

*   **Installation:**
    *   Download from [python.org](https://www.python.org/downloads/).
    *   Ensure "Add Python to PATH" is checked during Windows installation.
*   **Verify Installation:**
    ```bash
    python --version
    # or
    python3 --version
    ```
*   **Running Python Code:**
    1.  **Interactive Mode (REPL):**
        ```bash
        python # or python3
        >>> print("Hello")
        Hello
        >>> 2 + 3
        5
        >>> exit()
        ```
    2.  **From a File:**
        *   Create `my_script.py`:
            ```python
            # my_script.py
            print("Hello from a file!")
            name = input("What's your name? ")
            print(f"Nice to meet you, {name}!")
            ```
        *   Run from terminal:
            ```bash
            python my_script.py
            ```
*   **Integrated Development Environments (IDEs) & Editors:**
    *   **IDLE:** Python's default, basic IDE.
    *   **VS Code:** Popular, lightweight, powerful with extensions.
    *   **PyCharm:** Full-featured, specialized for Python.
    *   **Jupyter Notebook/Lab:** Interactive, great for data science.

## 3. Basic Syntax

*   **Comments:**
    *   Single-line: `# This is a comment`
    *   Multi-line (docstrings, not strict comments):
        ```python
        """
        This is a multi-line string.
        Often used as docstrings for functions/classes.
        """
        ```
*   **Variables:**
    *   No explicit declaration, type inferred at assignment.
    *   Case-sensitive (`myVar` is different from `myvar`).
    *   Convention: `snake_case` for variable and function names.
    *   Can reassign variables to different types.
    ```python
    x = 10          # int
    name = "Alice"  # str
    is_active = True # bool
    x = "hello"     # x is now a string
    ```
*   **Indentation:**
    *   **Crucial!** Defines code blocks (loops, functions, `if` statements).
    *   Standard: **4 spaces** per indent level.
    *   Mixing tabs and spaces can lead to `IndentationError`.
*   **Printing Output:**
    ```python
    print("Hello, World!")
    print("Value of x:", x)
    print(f"My name is {name} and I am {x} years old.") # f-strings (Python 3.6+)
    ```
*   **Getting Input:**
    ```python
    user_input = input("Enter something: ")
    print("You entered:", user_input)
    # input() always returns a string; convert for numbers
    age = int(input("Enter your age: "))
    ```

## 4. Data Types

Python has several built-in data types.

### Primitive Data Types

*   **Numbers:**
    *   **`int`** (integers): `1`, `100`, `-5`
    *   **`float`** (floating-point numbers): `3.14`, `2.0`, `-0.5`
    *   **`complex`** (complex numbers): `1 + 2j`
*   **Booleans:**
    *   **`bool`**: `True`, `False` (case-sensitive)
*   **Strings:**
    *   **`str`**: Sequence of characters. Immutable (cannot be changed after creation).
    *   Defined with single, double, or triple quotes.
    ```python
    s1 = 'hello'
    s2 = "world"
    s3 = """This is a multi-line string."""
    ```
    *   **String Operations:**
        *   Concatenation: `s1 + " " + s2`
        *   Repetition: `s1 * 3` (`'hellohellohello'`)
        *   Length: `len(s1)`
        *   Indexing: `s1[0]` (`'h'`), `s1[-1]` (`'o'`)
        *   Slicing: `s1[1:4]` (`'ell'`), `s1[:3]` (`'hel'`), `s1[2:]` (`'llo'`), `s1[::2]` (`'hlo'`)
        *   Methods: `.upper()`, `.lower()`, `.strip()`, `.replace()`, `.split()`, `.find()`, `.startswith()`, `.endswith()`
*   **`None` Type:**
    *   Represents the absence of a value.
    *   `my_variable = None`

### Collection Data Types

*   **Lists:**
    *   **`list`**: Ordered, mutable (changeable) sequence of items.
    *   Defined with square brackets `[]`. Can hold mixed data types.
    ```python
    my_list = [1, "apple", True, 3.14]
    ```
    *   **List Operations:**
        *   Access: `my_list[0]` (`1`), `my_list[-1]` (`3.14`)
        *   Slicing: `my_list[1:3]` (`['apple', True]`)
        *   Modify: `my_list[0] = 5` (`[5, "apple", True, 3.14]`)
        *   Add: `my_list.append("orange")`, `my_list.insert(1, "banana")`, `my_list.extend([10, 20])`
        *   Remove: `my_list.remove("apple")`, `my_list.pop()`, `del my_list[0]`
        *   Length: `len(my_list)`
        *   Sort: `my_list.sort()` (if homogeneous type)
*   **Tuples:**
    *   **`tuple`**: Ordered, **immutable** (unchangeable) sequence of items.
    *   Defined with parentheses `()`.
    *   Faster than lists for fixed data; used for function returns with multiple values.
    ```python
    my_tuple = (1, "apple", True)
    # my_tuple[0] = 5 # Error: Tuples are immutable
    ```
    *   **Tuple Operations:** Similar to lists for access, slicing, length.
*   **Dictionaries:**
    *   **`dict`**: Unordered collection of **key-value pairs**. Mutable.
    *   Keys must be unique and immutable (strings, numbers, tuples). Values can be any type.
    *   Defined with curly braces `{}`.
    ```python
    my_dict = {"name": "Alice", "age": 30, "city": "New York"}
    ```
    *   **Dictionary Operations:**
        *   Access value: `my_dict["name"]` (`'Alice'`), `my_dict.get("country", "USA")` (default value if key not found)
        *   Add/Modify: `my_dict["email"] = "alice@example.com"`, `my_dict["age"] = 31`
        *   Remove: `del my_dict["city"]`, `my_dict.pop("age")`
        *   Keys: `my_dict.keys()` (returns view object)
        *   Values: `my_dict.values()` (returns view object)
        *   Items: `my_dict.items()` (returns view of (key, value) tuples)
        *   Length: `len(my_dict)`
*   **Sets:**
    *   **`set`**: Unordered collection of **unique** items. Mutable.
    *   Defined with curly braces `{}` (or `set()` for empty set).
    *   Useful for membership testing and eliminating duplicate entries.
    ```python
    my_set = {1, 2, 3, 2, 4} # Result: {1, 2, 3, 4}
    ```
    *   **Set Operations:**
        *   Add: `my_set.add(5)`
        *   Remove: `my_set.remove(2)`, `my_set.discard(10)` (no error if not found)
        *   Union: `set1.union(set2)` (`|` operator)
        *   Intersection: `set1.intersection(set2)` (`&` operator)
        *   Difference: `set1.difference(set2)` (`-` operator)
        *   Length: `len(my_set)`

## 5. Operators

*   **Arithmetic Operators:** `+`, `-`, `*`, `/` (float division), `//` (integer division), `%` (modulus), `**` (exponentiation)
*   **Comparison Operators:** `==` (equal to), `!=` (not equal to), `<`, `>`, `<=`, `>=`
*   **Logical Operators:**
    *   `and`: Returns `True` if both operands are `True`.
    *   `or`: Returns `True` if at least one operand is `True`.
    *   `not`: Reverses the boolean state.
*   **Assignment Operators:** `=`, `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=`
*   **Identity Operators:**
    *   `is`: Returns `True` if two variables point to the same object in memory.
    *   `is not`: Returns `True` if two variables do *not* point to the same object.
*   **Membership Operators:**
    *   `in`: Returns `True` if a sequence contains a specified value.
    *   `not in`: Returns `True` if a sequence does *not* contain a specified value.

## 6. Control Flow

### `if`/`elif`/`else` Statements

Used for conditional execution.

```python
age = 20

if age < 13:
    print("Child")
elif 13 <= age < 18: # Can chain comparisons
    print("Teenager")
else:
    print("Adult")
```

### `for` Loops

Used for iterating over a sequence (list, tuple, string, dictionary, set, range).

```python
# Iterate over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# Iterate over a string
for char in "Python":
    print(char)

# Iterate using range()
# range(stop) -> 0 to stop-1
# range(start, stop) -> start to stop-1
# range(start, stop, step)
for i in range(5): # 0, 1, 2, 3, 4
    print(i)

# Iterate over dictionary items
my_dict = {"a": 1, "b": 2}
for key, value in my_dict.items():
    print(f"{key}: {value}")
```

### `while` Loops

Executes a block of code as long as a condition is true.

```python
count = 0
while count < 5:
    print(count)
    count += 1
```

### `break` and `continue`

*   **`break`**: Terminates the loop entirely.
*   **`continue`**: Skips the rest of the current iteration and proceeds to the next.

```python
for i in range(10):
    if i == 3:
        continue # Skip 3
    if i == 7:
        break    # Stop at 7
    print(i) # Output: 0, 1, 2, 4, 5, 6
```

## 7. Functions

Reusable blocks of code.

*   **Defining a Function:**
    ```python
    def greet(name):
        """This function greets the person passed in as a parameter.""" # Docstring
        print(f"Hello, {name}!")

    greet("Alice") # Calling the function
    ```
*   **Return Values:**
    ```python
    def add(a, b):
        return a + b

    result = add(5, 3)
    print(result) # 8
    ```
*   **Parameters:**
    *   **Positional Arguments:** `def func(a, b)`
    *   **Keyword Arguments:** `func(b=5, a=10)`
    *   **Default Arguments:**
        ```python
        def power(base, exp=2):
            return base ** exp
        print(power(3))    # 9 (3**2)
        print(power(3, 3)) # 27 (3**3)
        ```
    *   **Arbitrary Arguments (`*args`):** For an unknown number of positional arguments.
        ```python
        def sum_all(*numbers):
            total = 0
            for num in numbers:
                total += num
            return total
        print(sum_all(1, 2, 3)) # 6
        ```
    *   **Arbitrary Keyword Arguments (`**kwargs`):** For an unknown number of keyword arguments (passed as a dictionary).
        ```python
        def print_info(**kwargs):
            for key, value in kwargs.items():
                print(f"{key}: {value}")
        print_info(name="Bob", age=25)
        ```
*   **Scope:**
    *   **Local Scope:** Variables defined inside a function are local to that function.
    *   **Global Scope:** Variables defined outside any function are global.
    *   Use `global` keyword to modify a global variable inside a function (generally discouraged).
*   **Lambda Functions (Anonymous Functions):**
    *   Small, single-expression functions.
    *   `lambda arguments: expression`
    ```python
    add_one = lambda x: x + 1
    print(add_one(5)) # 6

    # Often used with higher-order functions like map(), filter(), sorted()
    numbers = [1, 2, 3, 4]
    squared = list(map(lambda x: x*x, numbers)) # [1, 4, 9, 16]
    ```

## 8. Modules and Packages

*   **Modules:** Python files (`.py`) containing code (functions, classes, variables).
*   **Packages:** Directories containing multiple modules and a special `__init__.py` file (can be empty), making Python treat the directory as a package.
*   **Importing:**
    ```python
    # my_module.py
    def hello():
        print("Hello from my_module!")
    my_var = 100

    # main.py
    import my_module
    my_module.hello()
    print(my_module.my_var)

    from my_module import hello, my_var
    hello()
    print(my_var)

    from my_module import hello as greet_func
    greet_func()
    ```
*   **Standard Library Modules (Examples):**
    *   `math`: Math functions (`sqrt`, `cos`, `pi`)
    *   `random`: Random number generation
    *   `os`: Operating system interaction (`os.path`, `os.environ`)
    *   `sys`: System-specific parameters and functions (`sys.argv`, `sys.exit`)
    *   `datetime`: Date and time objects
*   **Pip (Python's Package Installer):**
    *   Used to install, manage, and uninstall third-party packages from PyPI (Python Package Index).
    *   `pip install package_name`
    *   `pip uninstall package_name`
    *   `pip list`
    *   `pip freeze > requirements.txt` (saves installed packages to a file)
    *   `pip install -r requirements.txt` (installs packages from a file)

## 9. File I/O (Input/Output)

Interacting with files on the filesystem.

*   **Opening Files:**
    `open(filename, mode)`
    *   `filename`: Path to the file.
    *   `mode`:
        *   `'r'`: Read (default). Error if file doesn't exist.
        *   `'w'`: Write. Creates file if it doesn't exist, **overwrites** if it does.
        *   `'a'`: Append. Creates file if it doesn't exist, adds to end if it does.
        *   `'x'`: Create. Creates file, error if it already exists.
        *   `'b'`: Binary mode (e.g., `'rb'`, `'wb'`).
        *   `'+'`: Open for updating (read and write, e.g., `'r+'`, `'w+'`).
*   **Reading Files:**
    ```python
    # Using 'with' statement for automatic file closing (recommended)
    with open("my_file.txt", "r") as f:
        content = f.read()       # Reads entire file content as a single string
        print(content)

    with open("my_file.txt", "r") as f:
        line1 = f.readline()     # Reads one line
        print(line1)

    with open("my_file.txt", "r") as f:
        lines = f.readlines()    # Reads all lines into a list of strings
        for line in lines:
            print(line.strip())  # .strip() removes newline characters
    ```
*   **Writing Files:**
    ```python
    with open("new_file.txt", "w") as f:
        f.write("Hello, Python!\n")
        f.write("This is a new line.\n")

    with open("new_file.txt", "a") as f:
        f.write("Appending more content.\n")
    ```

## 10. Error Handling (Exceptions)

Handling unexpected events that disrupt normal program flow.

*   **`try`-`except` Block:**
    ```python
    try:
        # Code that might raise an exception
        result = 10 / 0
    except ZeroDivisionError:
        # Code to handle that specific exception
        print("Error: Cannot divide by zero!")
    except TypeError:
        # Handle another specific exception
        print("Error: Type mismatch!")
    except Exception as e: # Catch any other exception (general catch-all)
        print(f"An unexpected error occurred: {e}")
    else:
        # Code to run if no exception occurred in the try block
        print("Division successful.")
    finally:
        # Code that always runs, regardless of exceptions
        print("Execution finished.")
    ```
*   **Common Exceptions:**
    *   `ValueError`: Invalid value for an operation.
    *   `TypeError`: Operation on an inappropriate type.
    *   `NameError`: Undefined variable.
    *   `FileNotFoundError`: File not found.
    *   `IndexError`: Invalid index for a sequence.
    *   `KeyError`: Key not found in a dictionary.
*   **Raising Exceptions:**
    ```python
    def calculate_age(year_born):
        if year_born > 2023:
            raise ValueError("Year born cannot be in the future!")
        return 2023 - year_born

    try:
        age = calculate_age(2025)
    except ValueError as e:
        print(f"Caught error: {e}")
    ```

## 11. Object-Oriented Programming (OOP)

A programming paradigm based on the concept of "objects," which can contain data and code.

*   **Concepts:**
    *   **Class:** A blueprint for creating objects (e.g., `Car` class).
    *   **Object (Instance):** An individual instance of a class (e.g., `my_car = Car("Red", "Sedan")`).
    *   **Attribute:** Variables associated with a class or object (e.g., `Car.color`, `Car.model`).
    *   **Method:** Functions defined inside a class, operating on objects (e.g., `Car.start_engine()`).
*   **Defining a Class:**
    ```python
    class Dog:
        # Class attribute (shared by all instances)
        species = "Canis familiaris"

        def __init__(self, name, breed):
            """Constructor method, called when a new object is created."""
            self.name = name   # Instance attribute
            self.breed = breed # Instance attribute

        def bark(self):
            """An instance method."""
            print(f"{self.name} says Woof!")

        def describe(self):
            return f"{self.name} is a {self.breed} of {self.species}."

    # Creating objects (instances)
    my_dog = Dog("Buddy", "Golden Retriever")
    your_dog = Dog("Lucy", "Labrador")

    print(my_dog.name)        # Buddy
    print(my_dog.species)     # Canis familiaris
    my_dog.bark()             # Buddy says Woof!
    print(your_dog.describe()) # Lucy is a Labrador of Canis familiaris.
    ```
*   **Inheritance:**
    *   Allows a new class (child/derived) to inherit attributes and methods from an existing class (parent/base).
    *   Promotes code reusability.
    ```python
    class WorkingDog(Dog): # WorkingDog inherits from Dog
        def __init__(self, name, breed, job):
            super().__init__(name, breed) # Call parent class constructor
            self.job = job

        def perform_job(self):
            print(f"{self.name} is performing its job as a {self.job}.")

    police_dog = WorkingDog("Rex", "German Shepherd", "Police Dog")
    print(police_dog.name)      # Rex
    print(police_dog.species)   # Canis familiaris (inherited)
    police_dog.bark()           # Rex says Woof! (inherited)
    police_dog.perform_job()    # Rex is performing its job as a Police Dog.
    ```
*   **Polymorphism:**
    *   The ability of different objects to respond to the same method call in their own way.
    *   Python uses **Duck Typing**: "If it walks like a duck and quacks like a duck, then it's a duck."
*   **Encapsulation:**
    *   Bundling data (attributes) and methods that operate on the data within a single unit (class).
    *   Restricting direct access to some components of an object.
    *   **Conventions in Python:**
        *   `_attribute`: Suggests "protected" (for internal use, but accessible).
        *   `__attribute`: Name mangling occurs, making it harder to access directly (e.g., `_ClassName__attribute`).

## 12. Virtual Environments

*   **Problem:** Different projects may require different versions of the same library, or a specific set of dependencies. Installing globally can lead to conflicts.
*   **Solution:** Virtual environments create isolated Python environments for each project.
*   **Usage (`venv` module - built-in Python 3.3+):**
    1.  **Create:**
        ```bash
        python -m venv my_project_env
        ```
        (This creates a directory `my_project_env` containing a copy of Python interpreter and `pip`).
    2.  **Activate:**
        *   **Linux/macOS:**
            ```bash
            source my_project_env/bin/activate
            ```
        *   **Windows (Command Prompt):**
            ```bash
            my_project_env\Scripts\activate.bat
            ```
        *   **Windows (PowerShell):**
            ```powershell
            my_project_env\Scripts\Activate.ps1
            ```
        *   Your terminal prompt will often show `(my_project_env)` to indicate activation.
    3.  **Install Packages (while activated):**
        ```bash
        pip install requests numpy
        ```
        These packages are now only installed within `my_project_env`.
    4.  **Deactivate:**
        ```bash
        deactivate
        ```

## 13. Advanced/Common Concepts (Briefly)

*   **List Comprehensions:** Concise way to create lists.
    ```python
    squares = [x*x for x in range(10)] # [0, 1, 4, ..., 81]
    evens = [x for x in range(10) if x % 2 == 0] # [0, 2, 4, 6, 8]
    ```
*   **Generators:** Functions that yield values one at a time, allowing iteration without storing the entire sequence in memory.
    ```python
    def count_up_to(max):
        i = 1
        while i <= max:
            yield i # yield makes it a generator
            i += 1
    for num in count_up_to(5):
        print(num)
    ```
*   **Decorators:** Functions that modify or enhance other functions without changing their source code.
*   **Context Managers (`with` statement):** Used for resources that need to be set up and torn down (like files, locks, database connections).

## 15. Best Practices & Tips

*   **Read PEP 8:** Python's style guide for readable code.
*   **Use meaningful variable/function names.**
*   **Add docstrings and comments:** Explain *why*, not just *what*.
*   **Use virtual environments for every project.**

*   **Write tests:** Ensure your code works as expected.
*   **Fail fast:** Raise exceptions early when conditions are not met.
*   **Learn to use a debugger.**
*   **Practice regularly by building small projects.**
