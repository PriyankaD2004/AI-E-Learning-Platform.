## Detailed Notes on Python

### 1. Introduction to Python

*   **What is Python?**
    *   High-level, interpreted, general-purpose programming language.
    *   Created by Guido van Rossum, first released in 1991.
    *   **Design Philosophy:** Emphasizes code readability with its use of significant indentation.
    *   **"Zen of Python"**: `import this` in interpreter for a list of guiding principles (e.g., "Beautiful is better than ugly," "Readability counts").
*   **Key Features:**
    *   **Interpreted:** Code is executed line by line, no separate compilation step.
    *   **High-Level:** Abstract away low-level details, easier to write.
    *   **Dynamically Typed:** Variable types are determined at runtime, no explicit declaration needed.
    *   **Garbage-Collected:** Automatic memory management.
    *   **Cross-Platform:** Runs on Windows, macOS, Linux, etc.
    *   **Object-Oriented:** Supports classes and objects.
    *   **Extensible:** Can be extended with C/C++ modules.
    *   **Extensive Standard Library:** A rich collection of modules and packages.
    *   **Vast Ecosystem:** Many third-party libraries for various applications.
*   **Common Use Cases:**
    *   Web Development (Django, Flask)
    *   Data Science & Machine Learning (NumPy, Pandas, Scikit-learn, TensorFlow, PyTorch)
    *   Automation & Scripting
    *   Desktop GUI Development (Tkinter, PyQt)
    *   Game Development (Pygame)
    *   Network Programming
    *   Scientific & Numeric Computing

### 2. Python Setup & Execution

*   **Installation:** Download from [python.org](https://www.python.org/).
*   **Python Interpreter:**
    *   `python` or `python3` command in terminal to enter interactive mode.
    *   Type `exit()` or `Ctrl+D` to exit.
*   **Executing a Script:** `python your_script.py`
*   **IDE/Editor:** VS Code, PyCharm, Sublime Text, Jupyter Notebooks.

### 3. Basic Syntax & Concepts

*   **Comments:**
    *   Single-line: `# This is a comment`
    *   Multi-line (Docstrings): `"""This is a multi-line comment or docstring."""`
*   **Indentation:**
    *   **Crucial:** Defines code blocks (instead of braces `{}`).
    *   Convention: 4 spaces per indentation level.
    *   Mixing tabs and spaces can lead to `IndentationError`.
*   **Statements & Expressions:**
    *   **Statement:** A unit of code that performs an action (e.g., `x = 10`, `print("Hello")`).
    *   **Expression:** A piece of code that produces a value (e.g., `10 + 5`, `len("Python")`).
*   **Variables:**
    *   Names that refer to values in memory.
    *   No explicit type declaration needed (dynamic typing).
    *   `variable_name = value`
    *   Valid names: alphanumeric, underscore; cannot start with a number; case-sensitive.
    *   **Reserved Keywords:** `if`, `else`, `for`, `while`, `def`, `class`, `import`, `return`, `None`, `True`, `False`, etc. (Type `help("keywords")` in interpreter).

### 4. Data Types

Python has several built-in data types:

*   **Numeric Types:**
    *   `int`: Integers (e.g., `10`, `-5`, `0`).
    *   `float`: Floating-point numbers (e.g., `3.14`, `-0.5`, `2.0`).
    *   `complex`: Complex numbers (e.g., `1 + 2j`).
*   **Boolean Type:**
    *   `bool`: Represents truth values. `True` or `False`.
*   **String Type:**
    *   `str`: Sequence of characters. Enclosed in single (`'...'`) or double (`"..."`) quotes.
    *   Multi-line strings: Triple quotes (`'''...'''` or `"""..."""`).
    *   **Immutability:** Strings cannot be changed after creation.
    *   **Operations:** Concatenation (`+`), repetition (`*`), slicing (`[start:end:step]`), `len()`, methods (`.upper()`, `.lower()`, `.strip()`, `.split()`, `.join()`, `.format()`, f-strings).
    *   **f-strings (Formatted String Literals):** `name = "Alice"; age = 30; print(f"Name: {name}, Age: {age}")`
*   **None Type:**
    *   `None`: Represents the absence of a value. Often used as a placeholder or default value.
    *   `None` is its own type (`NoneType`).

### 5. Operators

*   **Arithmetic:** `+`, `-`, `*`, `/` (float division), `//` (integer division), `%` (modulo), `**` (exponentiation).
*   **Comparison:** `==` (equal to), `!=` (not equal to), `<`, `>`, `<=`, `>=`.
*   **Logical:** `and`, `or`, `not`.
*   **Assignment:** `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`, `//=`.
*   **Identity:** `is`, `is not` (checks if two variables refer to the *same object* in memory).
*   **Membership:** `in`, `not in` (checks if an element is present in a sequence).

### 6. Control Flow

*   **Conditional Statements (`if`/`elif`/`else`):**
    ```python
    age = 20
    if age < 13:
        print("Child")
    elif 13 <= age < 20:
        print("Teenager")
    else:
        print("Adult")
    ```
*   **Loops:**
    *   **`for` loop (iteration over sequences):**
        ```python
        for i in range(5): # range(start, stop, step) generates numbers
            print(i)
        
        fruits = ["apple", "banana", "cherry"]
        for fruit in fruits:
            print(fruit)
        
        # Enumerate for index and value
        for index, fruit in enumerate(fruits):
            print(f"{index}: {fruit}")
        ```
    *   **`while` loop (conditional repetition):**
        ```python
        count = 0
        while count < 3:
            print(count)
            count += 1
        ```
    *   **`break`:** Terminates the loop immediately.
    *   **`continue`:** Skips the rest of the current iteration and moves to the next.
    *   **`else` with loops:** Executes if the loop completes without a `break`.

### 7. Data Structures (Collections)

Python offers powerful built-in collections:

*   **Lists:**
    *   **Ordered, mutable, allows duplicates.**
    *   Defined with square brackets `[]`.
    *   `my_list = [1, "hello", 3.14, True]`
    *   **Operations:** Indexing (`[0]`), slicing (`[1:3]`), `len()`, `append()`, `insert()`, `extend()`, `remove()`, `pop()`, `sort()`, `reverse()`.
*   **Tuples:**
    *   **Ordered, immutable, allows duplicates.**
    *   Defined with parentheses `()` (or just commas).
    *   `my_tuple = (1, "hello", 3.14)`
    *   **Operations:** Indexing, slicing, `len()`, `count()`, `index()`.
    *   Often used for fixed collections or return values from functions.
*   **Dictionaries:**
    *   **Unordered (pre Python 3.7), ordered (Python 3.7+), mutable collection of key-value pairs.**
    *   Keys must be unique and immutable (strings, numbers, tuples). Values can be any type.
    *   Defined with curly braces `{}`.
    *   `my_dict = {"name": "Alice", "age": 30, "city": "NY"}`
    *   **Operations:** Accessing values (`my_dict["name"]`), adding/modifying (`my_dict["job"] = "Engineer"`), `len()`, `del`, `keys()`, `values()`, `items()`, `get()`.
*   **Sets:**
    *   **Unordered, mutable collection of unique elements.**
    *   Defined with curly braces `{}` (for non-empty) or `set()` (for empty).
    *   `my_set = {1, 2, 3, 3, 4}` -> `{1, 2, 3, 4}` (duplicates removed)
    *   **Operations:** `add()`, `remove()`, `pop()`, `union()`, `intersection()`, `difference()`.

### 8. Functions

*   **Definition:** Reusable blocks of code.
*   `def` keyword:
    ```python
    def greet(name):
        """This function greets the person passed in as a parameter."""
        print(f"Hello, {name}!")

    greet("Bob") # Calling the function
    ```
*   **Parameters & Arguments:**
    *   **Parameters:** Variables listed inside the parentheses in the function definition.
    *   **Arguments:** Values passed to the function when it's called.
*   **Return Value:**
    *   `return` statement sends a value back from the function.
    *   If no `return` or `return` without a value, function returns `None`.
    ```python
    def add(a, b):
        return a + b
    
    result = add(5, 3) # result will be 8
    ```
*   **Default Arguments:**
    ```python
    def greet_default(name="Guest"):
        print(f"Hello, {name}!")
    
    greet_default()        # "Hello, Guest!"
    greet_default("Alice") # "Hello, Alice!"
    ```
*   **Keyword Arguments:**
    *   Pass arguments by name, allowing flexibility in order.
    `greet(name="Charlie")`
*   **Arbitrary Arguments (`*args`, `**kwargs`):**
    *   `*args`: Collects positional arguments into a tuple.
    *   `**kwargs`: Collects keyword arguments into a dictionary.
    ```python
    def my_sum(*numbers):
        return sum(numbers)
    
    def print_info(**details):
        for key, value in details.items():
            print(f"{key}: {value}")
    
    print(my_sum(1, 2, 3)) # 6
    print_info(name="Eve", age=25) # name: Eve, age: 25
    ```
*   **Lambda Functions (Anonymous Functions):**
    *   Small, single-expression functions.
    *   `lambda arguments: expression`
    *   `multiply = lambda x, y: x * y`
    *   `print(multiply(2, 3))` -> 6
*   **Scope:**
    *   **Local:** Variables defined inside a function (exist only within that function).
    *   **Global:** Variables defined outside any function (accessible anywhere).
    *   **`global` keyword:** Used inside a function to modify a global variable.
    *   **LEGB Rule:** Local, Enclosing function locals, Global, Built-in.

### 9. Object-Oriented Programming (OOP)

*   **Concepts:**
    *   **Class:** A blueprint for creating objects (defines attributes and methods).
    *   **Object:** An instance of a class.
    *   **Attribute:** A variable associated with a class or object.
    *   **Method:** A function associated with a class or object.
    *   **Encapsulation:** Bundling data (attributes) and methods that operate on the data into a single unit (class).
    *   **Inheritance:** A class (child/derived) can inherit properties and methods from another class (parent/base).
    *   **Polymorphism:** Objects of different classes can be treated as objects of a common type.
    *   **Abstraction:** Hiding complex implementation details and showing only essential features.
*   **Class Definition:**
    ```python
    class Dog:
        # Class attribute (shared by all instances)
        species = "Canis familiaris"

        def __init__(self, name, age):
            """Constructor method, called when a new object is created."""
            self.name = name # Instance attribute
            self.age = age   # Instance attribute
            print(f"{self.name} the dog was born!")

        def bark(self):
            """Instance method."""
            return f"{self.name} says Woof!"

        def get_age_in_human_years(self):
            return self.age * 7

    # Creating objects (instantiation)
    my_dog = Dog("Buddy", 3)
    your_dog = Dog("Lucy", 5)

    print(my_dog.name)                  # Buddy
    print(my_dog.bark())                # Buddy says Woof!
    print(my_dog.species)               # Canis familiaris
    print(your_dog.get_age_in_human_years()) # 35
    ```
*   **`self`:** A reference to the current instance of the class. Must be the first parameter of instance methods.
*   **Special (Dunder) Methods:**
    *   Methods with double underscores (e.g., `__init__`, `__str__`, `__repr__`).
    *   `__str__(self)`: Returns a human-readable string representation of the object (used by `print()`).
    *   `__repr__(self)`: Returns an unambiguous string representation (used for debugging).
*   **Inheritance Example:**
    ```python
    class Labrador(Dog): # Labrador inherits from Dog
        def __init__(self, name, age, color):
            super().__init__(name, age) # Call parent class constructor
            self.color = color

        def retrieve(self, item):
            return f"{self.name} retrieves the {item}!"

    my_lab = Labrador("Max", 2, "golden")
    print(my_lab.bark())          # Max says Woof! (inherited method)
    print(my_lab.retrieve("ball")) # Max retrieves the ball!
    print(my_lab.color)           # golden
    ```

### 10. Modules and Packages

*   **Module:** A file containing Python definitions and statements (`.py` extension).
    *   **Importing:** `import module_name` or `from module_name import function_name` or `import module_name as alias`.
    ```python
    # my_module.py
    def hello():
        print("Hello from my_module!")

    my_variable = 100

    # main.py
    import my_module
    my_module.hello()
    print(my_module.my_variable)

    from my_module import hello, my_variable
    hello()
    print(my_variable)
    ```
*   **Package:** A directory containing multiple modules and an `__init__.py` file (can be empty).
    *   Used to organize related modules into a hierarchy.
    *   `__init__.py` makes Python treat the directory as a package.
    ```
    my_package/
    ├── __init__.py
    ├── module_a.py
    └── sub_package/
        ├── __init__.py
        └── module_b.py
    ```
    *   **Importing from a package:** `import my_package.module_a` or `from my_package.sub_package import module_b`

### 11. File I/O (Input/Output)

*   **Opening Files:** `open(filename, mode)`
    *   **Modes:**
        *   `'r'`: Read (default). Error if file doesn't exist.
        *   `'w'`: Write. Creates file if it doesn't exist, truncates (clears) it if it does.
        *   `'a'`: Append. Creates file if it doesn't exist, adds to end if it does.
        *   `'x'`: Exclusive creation. Fails if file already exists.
        *   `'b'`: Binary mode (e.g., `'rb'`, `'wb'`).
        *   `'t'`: Text mode (default).
*   **Reading:**
    *   `read()`: Reads entire file content as a single string.
    *   `readline()`: Reads one line.
    *   `readlines()`: Reads all lines into a list of strings.
*   **Writing:**
    *   `write(string)`: Writes a string to the file.
    *   `writelines(list_of_strings)`: Writes a list of strings.
*   **Closing Files:** `file_object.close()`
    *   **Crucial** to release file resources.
*   **`with` statement (Context Manager):**
    *   **Recommended** for file handling. Automatically closes the file.
    ```python
    # Writing to a file
    with open("my_file.txt", "w") as f:
        f.write("Hello, Python!\n")
        f.write("This is a new line.")

    # Reading from a file
    with open("my_file.txt", "r") as f:
        content = f.read()
        print(content)

    # Reading line by line
    with open("my_file.txt", "r") as f:
        for line in f:
            print(line.strip()) # .strip() removes newline characters
    ```

### 12. Error and Exception Handling

*   **Errors:** Problems that prevent the program from running (e.g., `SyntaxError`).
*   **Exceptions:** Errors detected during execution (e.g., `ZeroDivisionError`, `NameError`, `TypeError`, `FileNotFoundError`).
*   **`try...except` block:**
    ```python
    try:
        # Code that might raise an exception
        result = 10 / 0
    except ZeroDivisionError:
        # Code to handle that specific exception
        print("Cannot divide by zero!")
    except TypeError as e: # Catch a specific error and get its message
        print(f"Type error occurred: {e}")
    except Exception as e: # Catch any other exception
        print(f"An unexpected error occurred: {e}")
    else:
        # Code to execute if no exception was raised in the try block
        print("Division successful!")
    finally:
        # Code that always executes, regardless of exception or not
        print("Execution finished.")
    ```
*   **`raise` statement:**
    *   Used to intentionally trigger an exception.
    *   `raise ValueError("Invalid input provided.")`

### 13. Standard Library

Python comes with a "batteries-included" standard library:

*   **`os`:** Interact with the operating system (paths, environment variables).
*   **`sys`:** System-specific parameters and functions (interpreter version, exit program).
*   **`math`:** Mathematical functions (sin, cos, sqrt).
*   **`random`:** Generate pseudo-random numbers.
*   **`datetime`:** Work with dates and times.
*   **`json`:** Encode and decode JSON data.
*   **`csv`:** Read and write CSV (Comma Separated Values) files.
*   **`re`:** Regular expressions for pattern matching in strings.
*   **`collections`:** High-performance container datatypes (`defaultdict`, `deque`, `Counter`).
*   **`unittest`:** Framework for writing unit tests.

### 14. Virtual Environments

*   **Purpose:** Isolate project dependencies. Prevents conflicts between different projects requiring different versions of libraries.
*   **`venv` module (Python 3.3+):**
    1.  **Create:** `python3 -m venv myenv`
    2.  **Activate:**
        *   Linux/macOS: `source myenv/bin/activate`
        *   Windows: `myenv\Scripts\activate`
    3.  **Install packages (when activated):** `pip install requests`
    4.  **Deactivate:** `deactivate`
*   **`pip`:** Python's package installer.
    *   `pip install package_name`
    *   `pip uninstall package_name`
    *   `pip list`
    *   `pip freeze > requirements.txt` (saves current environment's packages)
    *   `pip install -r requirements.txt` (installs packages from a file)

### 15. Best Practices & Advanced Topics (Briefly)

*   **PEP 8:** Python Enhancement Proposal 8 – Style Guide for Python Code. Follow it for readable and consistent code.
    *   Use 4 spaces for indentation.
    *   Limit lines to 79 characters.
    *   Use meaningful names.
    *   Add blank lines for readability.
*   **Docstrings:** Write them for modules, classes, and functions to explain their purpose.
*   **Meaningful Variable Names:** `user_name` instead of `x` or `n`.
*   **DRY Principle:** Don't Repeat Yourself (use functions, classes).
*   **KISS Principle:** Keep It Simple, Stupid.
*   **Context Managers:** Using `with` for resources that need proper setup/teardown (files, locks, database connections).
*   **List/Dictionary Comprehensions:** Concise ways to create lists or dictionaries.
    *   `squares = [x**2 for x in range(10) if x % 2 == 0]`
*   **Generators:** Functions that `yield` values instead of `return`ing them, creating iterators that produce values on demand (memory efficient).
*   **Decorators:** Functions that modify or enhance other functions.
*   **Asynchronous Programming:** `asyncio` for concurrent execution, especially in I/O-bound tasks.
*   **Testing:** Write unit tests (`unittest`, `pytest`) to ensure code correctness.
