# Detailed Notes on Python

## 1. Introduction to Python

*   **What is Python?**
    *   A high-level, interpreted, general-purpose programming language.
    *   Created by Guido van Rossum and first released in 1991.
    *   Emphasizes code readability with its clean syntax and extensive use of whitespace.
    *   **Key Characteristics:**
        *   **Interpreted:** Code is executed line by line, no compilation step needed for most cases.
        *   **High-Level:** Abstracts away low-level memory management.
        *   **General-Purpose:** Used for web development, data science, AI/ML, automation, scripting, desktop apps, etc.
        *   **Dynamically Typed:** Variable types are determined at runtime. You don't declare `int x;`. Just `x = 10`.
        *   **Object-Oriented:** Supports classes and objects, inheritance, polymorphism.
        *   **Cross-Platform:** Runs on Windows, macOS, Linux, etc.
        *   **Extensible:** Can be extended with modules written in C/C++ (e.g., NumPy).
        *   **"Batteries Included":** Comes with a large standard library.

*   **Why Python is Popular:**
    *   **Readability:** Simple, clean syntax makes it easy to learn and understand.
    *   **Versatility:** Broad range of applications.
    *   **Large Community & Ecosystem:** Abundance of libraries, frameworks, and support.
    *   **Productivity:** Faster development due to less code and clear syntax.

## 2. Setting Up Python

*   **Installation:**
    *   Download from [python.org](https://www.python.org/).
    *   Use package managers (e.g., `apt` on Linux, Homebrew on macOS).
    *   **Recommended:** Install Python 3.x (current stable series).
*   **IDEs/Editors:**

## 3. Python Fundamentals

### 3.1 Syntax and Structure

*   **Indentation:** Python uses whitespace (spaces or tabs, usually 4 spaces) to define code blocks (functions, loops, classes). This is crucial and not just stylistic.
    ```python
    if True:
        print("This is inside the if block")
        print("So is this")
    print("This is outside the if block")
    ```
*   **Comments:**
    *   Single-line: `# This is a comment`
    *   Multi-line (docstrings): Triple quotes `"""This is a multi-line comment or docstring."""`
*   **Statements:** Each line of code is generally a statement. Semicolons are optional and rarely used to separate multiple statements on one line.
*   **Keywords:** Reserved words with special meanings (e.g., `if`, `else`, `def`, `class`, `import`, `True`, `False`, `None`).

### 3.2 Variables and Data Types

*   **Variables:**
    *   No explicit type declaration; types are inferred at runtime.
    *   Variable names are case-sensitive.
    *   Follow `snake_case` convention (`my_variable_name`).
    ```python
    name = "Alice"  # string
    age = 30        # integer
    height = 1.75   # float
    is_student = True # boolean
    ```
*   **Basic Data Types:**
    *   **`int` (Integers):** Whole numbers (e.g., `10`, `-5`, `1_000_000`).
    *   **`float` (Floating-point numbers):** Decimal numbers (e.g., `3.14`, `-0.5`).
    *   **`complex` (Complex numbers):** Numbers with real and imaginary parts (e.g., `3 + 2j`).
    *   **`bool` (Booleans):** `True` or `False`.
    *   **`str` (Strings):** Sequence of characters, immutable. Enclosed in single or double quotes.
        ```python
        message = "Hello, World!"
        multi_line = """This is a
        multi-line string."""
        # f-strings (formatted string literals) for easy embedding variables
        name = "Bob"
        print(f"My name is {name}") # Output: My name is Bob
        ```
*   **Collection Data Types:**
    *   **`list` (Lists):** Ordered, mutable sequence of items. Can contain mixed data types.
        ```python
        my_list = [1, "hello", 3.14]
        my_list.append(4) # [1, "hello", 3.14, 4]
        my_list[0] = 0    # [0, "hello", 3.14, 4]
        ```
    *   **`tuple` (Tuples):** Ordered, immutable sequence of items. Faster than lists for fixed collections.
        ```python
        my_tuple = (1, "hello", 3.14)
        # my_tuple.append(4) # Error: Tuples are immutable
        ```
    *   **`dict` (Dictionaries):** Unordered collection of key-value pairs. Keys must be unique and immutable (strings, numbers, tuples).
        ```python
        my_dict = {"name": "Alice", "age": 30}
        print(my_dict["name"]) # Output: Alice
        my_dict["city"] = "New York"
        ```
    *   **`set` (Sets):** Unordered collection of unique items. Useful for membership testing and removing duplicates.
        ```python
        my_set = {1, 2, 3, 2} # {1, 2, 3} (duplicates removed)
        my_set.add(4)
        print(2 in my_set) # Output: True
        ```

### 3.3 Operators

*   **Arithmetic:** `+`, `-`, `*`, `/` (float division), `//` (integer division), `%` (modulo), `**` (exponentiation).
*   **Comparison:** `==` (equal), `!=` (not equal), `<`, `>`, `<=`, `>=`.
*   **Logical:** `and`, `or`, `not`.
*   **Assignment:** `=`, `+=`, `-=`, `*=`, `/=`, etc.
*   **Identity:** `is`, `is not` (checks if two variables refer to the *same object* in memory).
*   **Membership:** `in`, `not in` (checks if an item is present in a sequence).

### 3.4 Control Flow

*   **`if`, `elif`, `else` Statements:** Conditional execution.
    ```python
    age = 20
    if age < 18:
        print("Minor")
    elif age < 65:
        print("Adult")
    else:
        print("Senior")
    ```
*   **`for` Loops:** Iterate over sequences (lists, tuples, strings, dictionaries, range objects).
    ```python
    # Iterate over a list
    fruits = ["apple", "banana", "cherry"]
    for fruit in fruits:
        print(fruit)

    # Iterate using range
    for i in range(5): # 0, 1, 2, 3, 4
        print(i)
    ```
*   **`while` Loops:** Repeat a block of code as long as a condition is true.
    ```python
    count = 0
    while count < 3:
        print(f"Count: {count}")
        count += 1
    ```
*   **`break` and `continue`:**
    *   `break`: Terminates the current loop entirely.
    *   `continue`: Skips the rest of the current iteration and proceeds to the next.

### 3.5 Functions

*   **Definition:** Defined using the `def` keyword. Can accept arguments and return values.
    ```python
    def greet(name):
        """This function greets the person passed in as a parameter."""
        return f"Hello, {name}!"

    message = greet("Alice")
    print(message)
    ```
*   **Arguments:**
    *   **Positional:** Ordered by position.
    *   **Keyword:** Passed by name (e.g., `greet(name="Bob")`).
    *   **Default Values:** `def func(param1, param2="default_value"):`
    *   **Arbitrary Positional (`*args`):** Collects extra positional arguments into a tuple.
        ```python
        def sum_all(*args):
            return sum(args)
        print(sum_all(1, 2, 3)) # Output: 6
        ```
    *   **Arbitrary Keyword (`**kwargs`):** Collects extra keyword arguments into a dictionary.
        ```python
        def print_info(**kwargs):
            for key, value in kwargs.items():
                print(f"{key}: {value}")
        print_info(name="Alice", age=30)
        ```
*   **Return Values:** Functions can return any type of object. If no `return` statement, `None` is returned implicitly.
*   **Lambda Functions (Anonymous Functions):** Small, single-expression functions defined with `lambda`.
    ```python
    add = lambda x, y: x + y
    print(add(5, 3)) # Output: 8
    ```
*   **Scope:**
    *   **LEGB Rule:** Local, Enclosing function locals, Global, Built-in. Python looks for variables in this order.
    *   `global` and `nonlocal` keywords can modify variables outside the current scope.

### 3.6 Object-Oriented Programming (OOP)

*   **Classes and Objects:**
    *   **Class:** A blueprint for creating objects (instances).
    *   **Object:** An instance of a class.
    ```python
    class Dog:
        # Class attribute (shared by all instances)
        species = "Canis familiaris"

        # Constructor method
        def __init__(self, name, age):
            self.name = name # Instance attribute
            self.age = age   # Instance attribute

        # Instance method
        def bark(self):
            return f"{self.name} says Woof!"

        # Another instance method
        def describe(self):
            return f"{self.name} is {self.age} years old."

    # Create objects (instances)
    my_dog = Dog("Buddy", 3)
    your_dog = Dog("Lucy", 5)

    print(my_dog.name)        # Output: Buddy
    print(my_dog.bark())      # Output: Buddy says Woof!
    print(Dog.species)        # Output: Canis familiaris
    ```
*   **`self`:** A reference to the current instance of the class, passed implicitly as the first argument to instance methods.
*   **`__init__` Method:** The constructor method, called automatically when a new object is created.
*   **Inheritance:** Allows a class (child/subclass) to inherit attributes and methods from another class (parent/superclass).
    ```python
    class GoldenRetriever(Dog):
        def __init__(self, name, age, color):
            super().__init__(name, age) # Call parent's constructor
            self.color = color

        def retrieve(self, item):
            return f"{self.name} retrieved the {item}!"

    golden = GoldenRetriever("Goldie", 2, "Golden")
    print(golden.describe())    # Inherited method
    print(golden.retrieve("ball"))
    ```
*   **Polymorphism:** Objects of different classes can be treated as objects of a common superclass. Method overriding is a form of polymorphism.
    ```python
    class Cat:
        def make_sound(self): return "Meow"
    class Dog:
        def make_sound(self): return "Woof"

    animals = [Cat(), Dog()]
    for animal in animals:
        print(animal.make_sound())
    ```
*   **Encapsulation:** Bundling data (attributes) and methods that operate on the data within a single unit (class). Python uses convention (e.g., `_protected`, `__private` name mangling) rather than strict access modifiers.

### 3.7 Modules and Packages

*   **Module:** A Python file (`.py`) containing code (functions, classes, variables).
*   **Package:** A directory containing multiple modules and an `__init__.py` file (even if empty, signifies it's a package).
*   **Importing:**
    ```python
    import math               # Imports the entire math module
    print(math.sqrt(16))

    from math import pi       # Imports specific items from a module
    print(pi)

    from collections import defaultdict as ddict # Import with an alias
    my_dict = ddict(int)
    ```
*   **`pip` (Python's package installer):** Used to install, upgrade, and manage third-party libraries/packages.
    ```bash
    pip install requests
    pip uninstall requests
    pip freeze > requirements.txt # Save installed packages to a file
    pip install -r requirements.txt # Install from a file
    ```

## 4. Advanced Python Concepts

### 4.1 Error Handling (`try`, `except`, `finally`)

*   Used to gracefully handle runtime errors (exceptions).
    ```python
    try:
        result = 10 / 0
    except ZeroDivisionError:
        print("Cannot divide by zero!")
    except TypeError as e:
        print(f"Type error: {e}")
    else:
        print("Division successful.") # Executes if no exception occurred
    finally:
        print("This block always executes.") # Always executes, regardless of exception
    ```
*   **`raise`:** To explicitly raise an exception.
*   **Custom Exceptions:** Define your own exception classes by inheriting from `Exception`.

### 4.2 File I/O (Input/Output)

*   **Opening Files:** `open(filename, mode)`
    *   `'r'`: read (default)
    *   `'w'`: write (truncates file if exists, creates if not)
    *   `'a'`: append (adds to end of file)
    *   `'x'`: create (raises error if file exists)
    *   `'t'`: text mode (default)
    *   `'b'`: binary mode
*   **Reading/Writing:**
    *   `read()`: Reads entire file content.
    *   `readline()`: Reads one line.
    *   `readlines()`: Reads all lines into a list.
    *   `write()`: Writes a string.
    *   `writelines()`: Writes a list of strings.
*   **Closing Files:** `file.close()` (important to release resources).
*   **Context Manager (`with` statement):** Preferred way; automatically closes the file even if errors occur.
    ```python
    # Writing to a file
    with open("my_file.txt", "w") as f:
        f.write("Hello from Python!\n")
        f.write("This is a new line.")

    # Reading from a file
    with open("my_file.txt", "r") as f:
        content = f.read()
        print(content)
    ```

### 4.3 List/Dictionary Comprehensions

*   Concise way to create lists or dictionaries.
    ```python
    # List comprehension
    squares = [x**2 for x in range(10) if x % 2 == 0] # [0, 4, 16, 36, 64]

    # Dictionary comprehension
    cubes_dict = {x: x**3 for x in range(5)} # {0: 0, 1: 1, 2: 8, 3: 27, 4: 64}
    ```

### 4.4 Generators

*   **Definition:** Functions that produce a sequence of results one at a time using the `yield` keyword, rather than `return`ing a single list.
*   **Benefits:** Memory efficient (especially for large sequences), iterable.
    ```python
    def fibonacci_generator(limit):
        a, b = 0, 1
        while a < limit:
            yield a
            a, b = b, a + b

    # Use the generator
    for num in fibonacci_generator(10):
        print(num) # Output: 0, 1, 1, 2, 3, 5, 8
    ```

### 4.5 Decorators

*   **Definition:** Functions that take another function as an argument, add some functionality, and return the modified function. Uses the `@` syntax.
*   **Common Uses:** Logging, authentication, caching, timing, etc.
    ```python
    def my_decorator(func):
        def wrapper(*args, **kwargs):
            print("Something is happening before the function is called.")
            result = func(*args, **kwargs)
            print("Something is happening after the function is called.")
            return result
        return wrapper

    @my_decorator
    def say_hello(name):
        print(f"Hello, {name}!")

    say_hello("Alice")
    ```

### 4.6 Iterators and Iterables

*   **Iterable:** An object that can be iterated over (e.g., list, tuple, string, dictionary). Has an `__iter__()` method.
*   **Iterator:** An object that represents a stream of data. Has `__iter__()` and `__next__()` methods. `__next__()` returns the next item or raises `StopIteration`.
    ```python
    my_list = [1, 2, 3]
    my_iterator = iter(my_list) # Get an iterator

    print(next(my_iterator)) # Output: 1
    print(next(my_iterator)) # Output: 2
    # print(next(my_iterator)) # Output: 3
    # print(next(my_iterator)) # Raises StopIteration
    ```

## 5. Python Ecosystem and Libraries

Python's strength lies in its vast collection of libraries.

*   **Web Development:**
    *   **Django:** High-level, full-stack framework for rapid development (ORM, admin panel, templating).
    *   **Flask:** Lightweight micro-framework, good for smaller APIs and web apps.
    *   **FastAPI:** Modern, fast (ASGI), web framework for building APIs with Python 3.7+ based on standard Python type hints.
*   **Data Science & Machine Learning:**
    *   **NumPy:** Fundamental package for scientific computing with Python, especially for arrays and matrices.
    *   **Pandas:** Data structures (DataFrames) and data analysis tools, making data manipulation easy.
    *   **Matplotlib:** Comprehensive library for creating static, animated, and interactive visualizations.
    *   **Seaborn:** Statistical data visualization library based on Matplotlib.
    *   **Scikit-learn:** Simple and efficient tools for data mining and data analysis (ML algorithms).
    *   **TensorFlow / PyTorch:** Open-source machine learning frameworks for deep learning.
*   **Automation & Scripting:**
    *   **`os` module:** Interact with the operating system (files, directories).
    *   **`sys` module:** Access system-specific parameters and functions (e.g., command-line arguments).
    *   **`subprocess` module:** Run external commands and processes.
    *   **`re` module:** Regular expressions for pattern matching in strings.
    *   **`shutil` module:** High-level file operations (copy, move, delete).
*   **GUI Development:**
    *   **Tkinter:** Python's de-facto standard GUI package (built-in).
    *   **PyQt / PySide:** Powerful cross-platform GUI toolkit bindings.
    *   **Kivy:** Open-source Python library for rapid development of applications that make use of novel user interfaces, such as multi-touch apps.
*   **Testing:**
    *   **`unittest`:** Python's built-in testing framework.
    *   **Pytest:** Popular third-party testing framework, known for its simplicity and extensibility.

## 6. Best Practices

*   **PEP 8:** Python Enhancement Proposal 8 defines style guidelines for Python code.
    *   Use 4 spaces for indentation.
    *   Limit line length to 79 characters.
    *   Use `snake_case` for variable and function names.
    *   Use `PascalCase` for class names.
    *   Add blank lines to separate functions and classes.
*   **Virtual Environments:** Always use them to manage project dependencies.
*   **Docstrings:** Write clear, concise docstrings for modules, classes, and functions using triple quotes.
*   **Comments:** Use comments to explain *why* certain code exists, not *what* it does (unless the "what" is non-obvious).
*   **Meaningful Names:** Use descriptive variable, function, and class names.
*   **Don't Repeat Yourself (DRY):** Refactor common code into functions or classes.
*   **Error Handling:** Anticipate and handle potential errors gracefully.
*   **Testing:** Write unit tests for your code.
*   **Version Control:** Use Git and GitHub/GitLab/Bitbucket.
*   **Dependency Management:** Keep a `requirements.txt` file up-to-date.
*   **Logging:** Use the `logging` module for more robust output than `print()` statements in production code.
