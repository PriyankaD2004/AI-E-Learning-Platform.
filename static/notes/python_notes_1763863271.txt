## Python: Comprehensive Notes

### 1. Introduction to Python

*   **What is Python?**
    *   A high-level, interpreted, general-purpose programming language.
    *   Created by Guido van Rossum and first released in 1991.
    *   Emphasizes code readability with its clean syntax and extensive use of whitespace.
*   **Key Features:**
    *   **High-level:** Abstracts away low-level details (like memory management).
    *   **Interpreted:** Code is executed line by line, no separate compilation step.
    *   **Dynamically Typed:** Variable types are determined at runtime, not compile time.
    *   **Object-Oriented:** Supports classes and objects.
    *   **Platform Independent:** Runs on Windows, macOS, Linux, etc., with minimal changes.
    *   **Extensible:** Can be extended with modules written in C/C++.
    *   **Large Standard Library:** Rich set of modules for various tasks (web, OS, math, etc.).
    *   **Extensive Community & Ecosystem:** Vast libraries (NumPy, Pandas, Django, Flask, TensorFlow, etc.).
*   **The Zen of Python (excerpt):**
    *   "Beautiful is better than ugly."
    *   "Explicit is better than implicit."
    *   "Simple is better than complex."
    *   "Readability counts."

### 2. Setup & Execution

*   **Installation:** Download from `python.org`. Use `pyenv` or `conda` for version management.
*   **Interactive Mode (REPL):**
    *   Type `python` or `python3` in your terminal.
    *   Execute code line by line.
    *   Exit with `exit()` or `Ctrl+D` (Linux/macOS), `Ctrl+Z` then `Enter` (Windows).
*   **Script Mode:**
    *   Save code in a `.py` file (e.g., `my_script.py`).
    *   Run from terminal: `python my_script.py`.
*   **Package Manager (pip):**
    *   `pip install <package_name>`: Install a package.
    *   `pip uninstall <package_name>`: Uninstall a package.
    *   `pip list`: List installed packages.
    *   `pip freeze > requirements.txt`: Save current environment packages.
    *   `pip install -r requirements.txt`: Install from a `requirements.txt` file.

### 3. Basic Syntax

*   **Comments:**
    *   Single-line: `# This is a comment`
    *   Multi-line (docstrings): `"""This is a multi-line comment or docstring."""`
*   **Indentation:**
    *   **CRUCIAL!** Defines code blocks (no curly braces `{}`).
    *   Usually 4 spaces per level (or 1 tab, but consistency is key).
*   **Variables:**
    *   No explicit declaration; type inferred.
    *   `name = "Alice"`
    *   `age = 30`
    *   `is_student = True`
    *   Naming conventions: `snake_case` for variables and functions.
*   **Basic Output:**
    *   `print("Hello, World!")`
    *   `print("My name is", name, "and I am", age, "years old.")`
    *   **f-strings (formatted string literals - Python 3.6+):**
        *   `print(f"My name is {name} and I am {age} years old.")`
*   **User Input:**
    *   `user_name = input("Enter your name: ")`
    *   `user_age = int(input("Enter your age: "))` (Note: `input()` returns string, convert if needed)

### 4. Data Types

*   **Numbers:**
    *   **Integers (`int`):** `10`, `-5`, `0`
    *   **Floating-point numbers (`float`):** `3.14`, `-0.5`, `2.0`
    *   **Complex numbers (`complex`):** `1 + 2j`
*   **Strings (`str`):**
    *   Ordered sequence of characters, immutable.
    *   `'hello'`, `"world"`, `'''multi-line'''`
    *   **Operations:**
        *   Concatenation: `s1 + s2`
        *   Repetition: `s * 3`
        *   Slicing: `s[start:end:step]` (`s[0]`, `s[1:5]`, `s[::-1]` for reverse)
        *   Methods: `.upper()`, `.lower()`, `.strip()`, `.replace()`, `.split()`, `.join()`
*   **Booleans (`bool`):**
    *   `True`, `False` (case-sensitive)
*   **Lists (`list`):**
    *   Ordered, mutable (changeable) sequence of items.
    *   `my_list = [1, "hello", 3.14, True]`
    *   **Operations:**
        *   Access: `my_list[0]`, `my_list[-1]`
        *   Slicing: `my_list[1:3]`
        *   Methods: `.append()`, `.insert()`, `.remove()`, `.pop()`, `.sort()`, `len()`, `sum()`, `max()`, `min()`
*   **Tuples (`tuple`):**
    *   Ordered, immutable (unchangeable) sequence of items.
    *   `my_tuple = (1, "hello", 3.14)`
    *   Often used for fixed collections of items or as dictionary keys.
    *   Access & Slicing similar to lists, but no modification methods.
*   **Dictionaries (`dict`):**
    *   Unordered collection of `key: value` pairs. Keys must be unique and immutable.
    *   `my_dict = {"name": "Alice", "age": 30, "city": "New York"}`
    *   **Operations:**
        *   Access value: `my_dict["name"]`
        *   Add/Modify: `my_dict["email"] = "alice@example.com"`
        *   Remove: `del my_dict["city"]`, `my_dict.pop("age")`
        *   Methods: `.keys()`, `.values()`, `.items()`
*   **Sets (`set`):**
    *   Unordered collection of unique items. Mutable.
    *   `my_set = {1, 2, 3, 3, 4}` (will become `{1, 2, 3, 4}`)
    *   **Operations:**
        *   Add: `my_set.add(5)`
        *   Remove: `my_set.remove(1)`
        *   Set operations: `union()`, `intersection()`, `difference()`
    *   **Frozenset (`frozenset`):** Immutable version of a set.

### 5. Operators

*   **Arithmetic:** `+`, `-`, `*`, `/` (float division), `//` (integer division), `%` (modulo), `**` (exponentiation)
*   **Comparison:** `==` (equal to), `!=` (not equal to), `<`, `>`, `<=`, `>=`
*   **Assignment:** `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`, `//=`
*   **Logical:** `and`, `or`, `not`
*   **Identity:** `is`, `is not` (checks if two variables refer to the *same object* in memory)
*   **Membership:** `in`, `not in` (checks if an item exists in a sequence)

### 6. Control Flow

*   **Conditional Statements (`if`, `elif`, `else`):**
    ```python
    age = 20
    if age < 18:
        print("Minor")
    elif age >= 18 and age < 65:
        print("Adult")
    else:
        print("Senior")
    ```
*   **`for` Loops:**
    *   Iterate over a sequence (list, tuple, string, dictionary, set, range).
    ```python
    fruits = ["apple", "banana", "cherry"]
    for fruit in fruits:
        print(fruit)

    for i in range(5): # 0, 1, 2, 3, 4
        print(i)

    # Iterating through dictionary
    my_dict = {"a": 1, "b": 2}
    for key, value in my_dict.items():
        print(f"{key}: {value}")
    ```
*   **`while` Loops:**
    *   Execute a block of code repeatedly as long as a condition is true.
    ```python
    count = 0
    while count < 3:
        print(f"Count is {count}")
        count += 1
    ```
*   **`break` and `continue`:**
    *   `break`: Terminates the current loop entirely.
    *   `continue`: Skips the rest of the current iteration and proceeds to the next.
    ```python
    for i in range(10):
        if i == 3:
            continue # Skip 3
        if i == 7:
            break    # Exit loop at 7
        print(i)
    ```

### 7. Functions

*   **Defining a function:**
    ```python
    def greet(name):
        """This function greets the person passed in as a parameter."""
        print(f"Hello, {name}!")

    greet("Alice") # Calling the function
    ```
*   **Return Values:**
    ```python
    def add(a, b):
        return a + b

    result = add(5, 3) # result will be 8
    ```
*   **Parameters:**
    *   **Positional arguments:** Passed in order.
    *   **Keyword arguments:** Passed by name. `greet(name="Bob")`
    *   **Default parameters:**
        ```python
        def power(base, exp=2):
            return base ** exp
        print(power(3))    # 9
        print(power(2, 3)) # 8
        ```
    *   **Arbitrary Arguments (`*args` and `**kwargs`):**
        *   `*args`: Collects extra positional arguments into a tuple.
        *   `**kwargs`: Collects extra keyword arguments into a dictionary.
        ```python
        def my_sum(*numbers):
            return sum(numbers)
        print(my_sum(1, 2, 3)) # 6

        def describe_person(**details):
            for key, value in details.items():
                print(f"{key}: {value}")
        describe_person(name="John", age=30, occupation="Engineer")
        ```
*   **Lambda Functions (Anonymous Functions):**
    *   Small, single-expression functions.
    *   `add_one = lambda x: x + 1`
    *   `print(add_one(5))` # 6
    *   Often used with `map()`, `filter()`, `sorted()`.

### 8. Object-Oriented Programming (OOP)

*   **Classes:** Blueprints for creating objects.
*   **Objects:** Instances of a class.
*   **Attributes:** Variables belonging to an object (data).
*   **Methods:** Functions belonging to an object (behavior).
*   **`self`:** Reference to the current instance of the class (must be the first parameter of any method).
*   **`__init__` (Constructor):** Special method called when an object is created.
    ```python
    class Dog:
        # Class attribute
        species = "Canis familiaris"

        def __init__(self, name, age):
            self.name = name # Instance attribute
            self.age = age   # Instance attribute

        def bark(self):
            return f"{self.name} says Woof!"

        def get_age_in_dog_years(self):
            return self.age * 7

    # Create objects (instances)
    my_dog = Dog("Buddy", 3)
    your_dog = Dog("Lucy", 5)

    print(my_dog.name)        # Buddy
    print(my_dog.species)     # Canis familiaris
    print(my_dog.bark())      # Buddy says Woof!
    print(your_dog.get_age_in_dog_years()) # 35
    ```
*   **Inheritance:**
    *   A class can inherit attributes and methods from another class (parent/base class).
    *   `class GoldenRetriever(Dog):`
    *   `super().__init__(name, age)`: Calls the parent class's constructor.
*   **Polymorphism:** Objects of different classes can be treated as objects of a common type.
*   **Encapsulation:** Bundling data (attributes) and methods that operate on the data within a single unit (class). (Often achieved with private attributes, though Python uses convention with `_` or `__`).

### 9. Modules and Packages

*   **Module:** A file containing Python definitions and statements (`.py` extension).
*   **Package:** A directory containing multiple modules and an `__init__.py` file (can be empty).
*   **Importing:**
    *   `import math`: Imports the entire `math` module. Access via `math.sqrt()`.
    *   `from math import sqrt, pi`: Imports specific items. Access via `sqrt()`, `pi`.
    *   `from math import *`: Imports all public items (generally discouraged).
    *   `import os as operating_system`: Imports with an alias.
*   **Standard Library:** Modules built into Python (e.g., `os`, `sys`, `datetime`, `random`, `json`, `re`).

### 10. File I/O (Input/Output)

*   **Opening a file:** `open(filename, mode)`
    *   `mode`: `'r'` (read, default), `'w'` (write, overwrites), `'a'` (append), `'x'` (create new file, error if exists), `'b'` (binary), `'t'` (text, default).
*   **Reading:**
    *   `f.read()`: Read entire file content.
    *   `f.readline()`: Read one line.
    *   `f.readlines()`: Read all lines into a list.
*   **Writing:**
    *   `f.write(string)`: Writes string to file.
*   **Closing:** `f.close()` (Important to release resources).
*   **`with` statement (Recommended for files):**
    *   Automatically handles closing the file, even if errors occur.
    ```python
    # Writing to a file
    with open("my_file.txt", "w") as f:
        f.write("Hello from Python!\n")
        f.write("This is a new line.\n")

    # Reading from a file
    with open("my_file.txt", "r") as f:
        content = f.read()
        print(content)

    # Reading line by line
    with open("my_file.txt", "r") as f:
        for line in f:
            print(line.strip()) # .strip() removes newline characters
    ```

### 11. Error Handling (`try-except`)

*   **`try` block:** Code that might raise an exception.
*   **`except` block:** Code to execute if an exception occurs.
*   **`else` block:** (Optional) Code to execute if no exception occurred in `try`.
*   **`finally` block:** (Optional) Code to execute regardless of whether an exception occurred or not (e.g., for cleanup).
    ```python
    try:
        num1 = int(input("Enter a number: "))
        num2 = int(input("Enter another number: "))
        result = num1 / num2
        print(f"Result: {result}")
    except ValueError:
        print("Invalid input! Please enter integers.")
    except ZeroDivisionError:
        print("Error: Cannot divide by zero!")
    except Exception as e: # Catch any other unexpected error
        print(f"An unexpected error occurred: {e}")
    else:
        print("Division successful.")
    finally:
        print("Execution of try-except block finished.")
    ```
*   **`raise` statement:** To manually raise an exception.

### 12. Advanced Topics (Brief Mention)

*   **Generators:** Functions that return an iterator that produces a sequence of results one at a time using `yield`. Memory efficient.
*   **Decorators:** Functions that modify the behavior of other functions or methods without permanently altering them.
*   **Context Managers:** Objects that define the runtime context using `with` statements (like file I/O).
*   **List Comprehensions:** Concise way to create lists.
    *   `squares = [x**2 for x in range(10) if x % 2 == 0]`
*   **Dictionary/Set Comprehensions:** Similar concise creation for dicts/sets.
*   **Iterators:** Objects that represent a stream of data; implement `__iter__()` and `__next__()`.
