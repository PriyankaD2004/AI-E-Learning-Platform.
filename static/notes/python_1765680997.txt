Python is a high-level, interpreted, general-purpose programming language known for its readability and versatility. These notes cover its core concepts, advanced features, and practical considerations.

---

## Detailed Notes on Python

### 1. Introduction to Python

*   **What is Python?**
    *   **High-Level:** Abstracts away low-level details (like memory management).
    *   **Interpreted:** Code is executed line by line, not compiled entirely before running.
    *   **General-Purpose:** Used for a wide variety of applications.
    *   **Dynamically Typed:** Variable types are determined at runtime.
    *   **Strongly Typed:** Types are not implicitly converted in ways that might lead to data loss (e.g., you can't add a string and an integer directly).
    *   **Object-Oriented:** Supports OOP paradigms (classes, objects, inheritance).
    *   **Open Source:** Free to use and distribute.

*   **Key Features:**
    *   **Readability:** Emphasizes clear, concise syntax (PEP 8).
    *   **Simplicity:** Easy to learn and use.
    *   **Large Standard Library:** Rich set of modules for various tasks (e.g., `os`, `sys`, `math`, `json`).
    *   **Cross-Platform:** Runs on Windows, macOS, Linux, etc.
    *   **Extensible:** Can be combined with code written in C/C++.
    *   **Embeddable:** Can be embedded into other applications.

*   **Common Use Cases:**
    *   Web Development (Django, Flask, FastAPI)
    *   Data Science & Machine Learning (NumPy, Pandas, SciPy, Scikit-learn, TensorFlow, PyTorch)
    *   Automation & Scripting
    *   Artificial Intelligence
    *   Desktop GUI Development (Tkinter, PyQt)
    *   Game Development (Pygame)
    *   Networking
    *   Scientific Computing

*   **Basic Syntax:**
    *   **Comments:** `# single line`, `""" multi-line string """` (often used for docstrings).
    *   **Indentation:** Uses whitespace (4 spaces recommended by PEP 8) to define code blocks, *not* curly braces. This is crucial!
    *   **Statements:** End of a line usually marks the end of a statement.
    *   **Variables:** No explicit declaration; assigned values determine type.
        ```python
        x = 10          # integer
        name = "Alice"  # string
        is_active = True # boolean
        ```
    *   **`print()` function:** Outputs data to the console.
        ```python
        print("Hello, Python!")
        ```

### 2. Data Types & Structures

#### 2.1 Primitive Data Types

*   **`int` (Integers):** Whole numbers (e.g., `1`, `-5`, `1000`). Arbitrary precision.
*   **`float` (Floating-Point Numbers):** Numbers with a decimal point (e.g., `3.14`, `-0.5`, `2.0`).
*   **`str` (Strings):** Sequence of characters, immutable. Enclosed in single or double quotes.
    *   **Indexing & Slicing:** Access characters/sub-strings (e.g., `s[0]`, `s[1:4]`).
    *   **Methods:** `len()`, `upper()`, `lower()`, `strip()`, `split()`, `join()`, `find()`, `replace()`.
    *   **f-strings (Formatted String Literals):** `f"Name: {name}, Age: {age}"` (Python 3.6+)
*   **`bool` (Booleans):** `True` or `False`. Used for logical operations.
*   **`NoneType` (None):** Represents the absence of a value or a null value.

#### 2.2 Collection Data Types

*   **`list`:**
    *   **Ordered, mutable, heterogeneous.**
    *   Defined using square brackets `[]`.
    *   **Methods:** `append()`, `extend()`, `insert()`, `remove()`, `pop()`, `sort()`, `reverse()`, `index()`, `count()`.
    *   Can contain elements of different types.
    *   Examples: `[1, 2, "hello", True]`, `my_list = []`
*   **`tuple`:**
    *   **Ordered, immutable, heterogeneous.**
    *   Defined using parentheses `()`.
    *   Faster than lists for iteration when content doesn't need to change.
    *   Used for fixed collections of items.
    *   Examples: `(1, 2, "a")`, `my_tuple = ()`
*   **`dict` (Dictionary):**
    *   **Unordered collection of key-value pairs** (ordered in Python 3.7+ by insertion).
    *   **Mutable.** Keys must be unique and immutable (strings, numbers, tuples). Values can be any type.
    *   Defined using curly braces `{}`.
    *   **Methods:** `keys()`, `values()`, `items()`, `get()`, `update()`, `pop()`.
    *   Examples: `{'name': 'Alice', 'age': 30}`, `my_dict = {}`
*   **`set`:**
    *   **Unordered collection of unique elements.**
    *   **Mutable.**
    *   Defined using curly braces `{}` (or `set()` for an empty set).
    *   Useful for membership testing, removing duplicates, and mathematical set operations (union, intersection, difference).
    *   Examples: `{1, 2, 3}`, `my_set = set()`
*   **Type Conversion:**
    *   `int()`, `float()`, `str()`, `bool()`, `list()`, `tuple()`, `dict()`, `set()` can be used to convert between types where applicable.

### 3. Control Flow

*   **Conditional Statements (`if`, `elif`, `else`):**
    ```python
    age = 20
    if age < 18:
        print("Minor")
    elif age < 65:
        print("Adult")
    else:
        print("Senior")
    ```
*   **`for` Loops:** Iterate over sequences (lists, tuples, strings, dictionaries, sets) or other iterables.
    ```python
    for item in [1, 2, 3]:
        print(item)
    for i in range(5): # 0, 1, 2, 3, 4
        print(i)
    ```
*   **`while` Loops:** Execute a block of code repeatedly as long as a condition is true.
    ```python
    count = 0
    while count < 3:
        print(count)
        count += 1
    ```
*   **Loop Control Statements:**
    *   **`break`:** Terminates the loop entirely.
    *   **`continue`:** Skips the rest of the current iteration and moves to the next.
    *   **`pass`:** A null operation; nothing happens. Used as a placeholder where a statement is syntactically required.

### 4. Functions

*   **Definition:** Defined using the `def` keyword.
    ```python
    def greet(name):
        """This function greets the person passed in as a parameter."""
        return f"Hello, {name}!"

    message = greet("Alice")
    print(message)
    ```
*   **Parameters & Arguments:**
    *   **Positional Arguments:** Matched by position.
    *   **Keyword Arguments:** Matched by name (e.g., `func(name="Alice")`).
    *   **Default Parameters:** Provide a default value if not supplied (e.g., `def greet(name="Guest"):`).
    *   **Arbitrary Positional Arguments (`*args`):** Collects extra positional arguments into a tuple.
    *   **Arbitrary Keyword Arguments (`**kwargs`):** Collects extra keyword arguments into a dictionary.
*   **`return` Statement:** Returns a value from the function. If omitted, the function implicitly returns `None`.
*   **Docstrings:** Multi-line strings used to document functions, classes, and modules (accessed via `__doc__` or `help()`).
*   **Scope:** Determines where a variable is accessible (LEGB rule: Local, Enclosing, Global, Built-in).
*   **Lambda Functions (Anonymous Functions):** Small, single-expression functions, defined with `lambda`.
    ```python
    add = lambda x, y: x + y
    print(add(5, 3)) # Output: 8
    ```
*   **Recursion:** A function calling itself. Requires a base case to prevent infinite loops.

### 5. Object-Oriented Programming (OOP)

*   **Concepts:**
    *   **Encapsulation:** Bundling data (attributes) and methods that operate on the data within a single unit (class).
    *   **Inheritance:** A class can inherit attributes and methods from another class (parent/child).
    *   **Polymorphism:** Objects of different classes can be treated as objects of a common type (duck typing in Python).
    *   **Abstraction:** Hiding complex implementation details and showing only essential features.
*   **Classes:** Blueprints for creating objects. Defined with the `class` keyword.
    ```python
    class Dog:
        # Class attribute
        species = "Canis familiaris"

        def __init__(self, name, age):
            # Instance attributes
            self.name = name
            self.age = age

        # Instance method
        def bark(self):
            return f"{self.name} says Woof!"

        # Another instance method
        def description(self):
            return f"{self.name} is {self.age} years old."
    ```
*   **Objects:** Instances of a class.
    ```python
    my_dog = Dog("Buddy", 3) # Creating an object
    print(my_dog.description())
    print(my_dog.species)
    ```
*   **`__init__` Method (Constructor):** A special method called automatically when a new object is created. Initializes instance attributes. `self` refers to the instance of the class.
*   **Attributes:** Variables associated with a class or object (e.g., `name`, `age`).
*   **Methods:** Functions defined inside a class that operate on the object's data.
*   **Inheritance:**
    ```python
    class GoldenRetriever(Dog):
        def __init__(self, name, age, color):
            super().__init__(name, age) # Call parent's constructor
            self.color = color

        def fetch(self):
            return f"{self.name} is fetching the ball!"

    golden = GoldenRetriever("Goldie", 2, "golden")
    print(golden.description())
    print(golden.fetch())
    print(golden.bark())
    ```
*   **Special (Magic/Dunder) Methods:** Methods with double underscores (e.g., `__str__`, `__len__`, `__add__`). They define how objects behave in certain situations.
    *   `__str__`: Defines the string representation of an object (for `str()` and `print()`).
    *   `__repr__`: Defines the "official" string representation (for developers).

### 6. Modules & Packages

*   **Modules:** A Python file (`.py`) containing Python definitions and statements.
*   **Packages:** A way of organizing related modules into a directory hierarchy (must contain an `__init__.py` file, even if empty, for Python 3.2 and earlier; optional for 3.3+ but good practice).
*   **`import` Statement:** Used to bring modules or specific items from modules into the current scope.
    *   `import module_name`: Imports the entire module.
    *   `import module_name as alias`: Imports with an alias.
    *   `from module_name import item_name`: Imports specific items.
    *   `from package_name import module_name`: Imports a module from a package.
    *   `from package_name.module_name import item_name`: Imports an item from a module within a package.
*   **Standard Library:** Python's extensive collection of built-in modules (e.g., `math`, `os`, `sys`, `datetime`, `json`, `random`).
*   **Third-Party Packages:** Developed by the community and installed via `pip` (Python's package installer).
    *   **PyPI (Python Package Index):** The official repository for third-party Python packages.
    *   **`pip install package_name`:** Installs a package.
    *   **`pip freeze > requirements.txt`:** Generates a list of installed packages and their versions.
    *   **`pip install -r requirements.txt`:** Installs packages from a requirements file.

### 7. Error Handling

*   **Exceptions:** Events detected during execution that interrupt the normal flow of a program.
*   **`try`, `except`, `else`, `finally` Block:**
    *   **`try`:** Code that might raise an exception.
    *   **`except ExceptionType as e`:** Catches and handles specific exceptions. Can have multiple `except` blocks.
    *   **`else`:** Executed if no exception occurred in the `try` block.
    *   **`finally`:** Always executed, regardless of whether an exception occurred or not (useful for cleanup).
    ```python
    try:
        result = 10 / 0
    except ZeroDivisionError:
        print("Cannot divide by zero!")
    except TypeError as e:
        print(f"Type error: {e}")
    except Exception as e: # Catch all other exceptions
        print(f"An unexpected error occurred: {e}")
    else:
        print(f"Division successful, result: {result}")
    finally:
        print("Execution finished.")
    ```
*   **`raise` Statement:** Used to explicitly raise an exception.
    ```python
    def check_age(age):
        if age < 0:
            raise ValueError("Age cannot be negative.")
        print(f"Age is {age}")
    ```
*   **Common Built-in Exceptions:** `SyntaxError`, `IndentationError`, `NameError`, `TypeError`, `ValueError`, `IndexError`, `KeyError`, `FileNotFoundError`, `ZeroDivisionError`, `AttributeError`.

### 8. File I/O (Input/Output)

*   **Opening Files:** `open(filename, mode)`
    *   `'r'`: Read (default).
    *   `'w'`: Write (truncates file if it exists, creates if not).
    *   `'a'`: Append (adds to end of file, creates if not).
    *   `'x'`: Exclusive creation (fails if file exists).
    *   `'b'`: Binary mode (e.g., `'rb'`, `'wb'`).
    *   `'t'`: Text mode (default).
    *   `'+'`: Open for updating (read and write).
*   **Reading Files:**
    *   `file.read()`: Reads entire file content as a single string.
    *   `file.readline()`: Reads one line at a time.
    *   `file.readlines()`: Reads all lines into a list of strings.
    *   Iterating over a file object: `for line in file:` (efficient for large files).
*   **Writing Files:**
    *   `file.write(string)`: Writes a string to the file.
    *   `file.writelines(list_of_strings)`: Writes a list of strings to the file.
*   **Closing Files:** `file.close()`. **Crucial** to release file resources.
*   **`with` Statement (Context Manager):** The preferred way to handle files, as it ensures the file is automatically closed, even if errors occur.
    ```python
    # Writing
    with open("my_file.txt", "w") as f:
        f.write("Hello from Python!\n")
        f.write("This is a new line.")

    # Reading
    with open("my_file.txt", "r") as f:
        content = f.read()
        print(content)
    ```

### 9. Advanced Topics (Brief Overview)

*   **Decorators:** Functions that modify the behavior of other functions without permanently altering them. Uses `@decorator_name` syntax.
    ```python
    def my_decorator(func):
        def wrapper(*args, **kwargs):
            print("Something is happening before the function is called.")
            result = func(*args, **kwargs)
            print("Something is happening after the function is called.")
            return result
        return wrapper

    @my_decorator
    def say_hello(name):
        print(f"Hello, {name}!")

    say_hello("World")
    ```
*   **Generators:** Functions that produce a sequence of results one at a time using the `yield` keyword, allowing for lazy evaluation and memory efficiency. They are iterators.
    ```python
    def fibonacci_sequence(n):
        a, b = 0, 1
        for _ in range(n):
            yield a
            a, b = b, a + b

    for num in fibonacci_sequence(5):
        print(num) # 0, 1, 1, 2, 3
    ```
*   **Context Managers:** Objects that define `__enter__` and `__exit__` methods, allowing them to be used with the `with` statement (e.g., `open()` function).
*   **List/Dict/Set Comprehensions:** Concise ways to create lists, dictionaries, or sets based on existing iterables.
    *   `squares = [x**2 for x in range(10) if x % 2 == 0]`
    *   `my_dict = {f"key_{i}": i for i in range(5)}`
*   **Iterators:** Objects that implement the iterator protocol (`__iter__()` and `__next__()` methods), allowing them to be iterated upon (e.g., in `for` loops).
*   **Type Hinting (PEP 484):** Adding optional static type annotations to variables, function parameters, and return values to improve code readability and allow for static analysis (e.g., `def greet(name: str) -> str:`).
*   **Concurrency & Parallelism:**
    *   **`threading` module:** For I/O-bound tasks. Python's Global Interpreter Lock (GIL) limits true parallelism for CPU-bound tasks in multi-threaded programs.
    *   **`multiprocessing` module:** For CPU-bound tasks, bypasses the GIL by using separate processes.
    *   **`asyncio` module:** For asynchronous I/O-bound concurrency (non-blocking operations).

### 10. Best Practices & Style Guide (PEP 8)

*   **PEP 8:** The official style guide for Python code.
    *   **Indentation:** 4 spaces per level.
    *   **Line Length:** Max 79 characters (or 99 for some projects).
    *   **Naming Conventions:**
        *   `lowercase_with_underscores` for variables, functions, methods.
        *   `CamelCase` for class names.
        *   `UPPERCASE_WITH_UNDERSCORES` for constants.
        *   `_single_leading_underscore`: Suggests "internal use only" (not enforced).
        *   `__double_leading_underscore`: Name mangling for class attributes.
    *   **Blank Lines:** Use to separate logical blocks of code.
    *   **Imports:** Group imports, typically `standard library`, `third-party`, `local application` imports, each group sorted alphabetically.
*   **Docstrings:** Write clear and concise docstrings for modules, classes, and functions.
*   **Comments:** Use sparingly for "why" not "what."
*   **Virtual Environments:** Use `venv` or `conda` to create isolated environments for project dependencies to avoid conflicts.
    *   `python -m venv myenv`
    *   `source myenv/bin/activate` (Linux/macOS)
    *   `myenv\Scripts\activate` (Windows)
*   **Testing:** Write unit tests (`unittest`, `pytest`) to ensure code correctness and prevent regressions.
*   **Version Control:** Use `git` for tracking changes in your code.

### 12. Why Python? (Summary of Advantages & Disadvantages)

*   **Advantages:**
    *   Easy to learn and read.
    *   Versatile with a wide range of applications.
    *   Huge and active community.
    *   Extensive standard and third-party libraries.
    *   Excellent for rapid prototyping.
    *   Strong support for various programming paradigms.
*   **Disadvantages:**
    *   **Speed:** Generally slower than compiled languages like C++ or Java due to being interpreted and dynamically typed (especially for CPU-bound tasks).
    *   **GIL (Global Interpreter Lock):** In CPython (the most common implementation), the GIL limits true parallelism in multi-threaded programs, allowing only one thread to execute Python bytecode at a time.
    *   **Memory Consumption:** Can be more memory-intensive than lower-level languages.
    *   **Runtime Errors:** Dynamic typing means some errors are only caught at runtime, not during compilation.
